## 📖 算法原理

**声称质量水平检验法（Declared Quality Level Testing, DQL 检验）** 是一种基于 **统计假设检验** 框架的质量验证方法。其典型应用场景是：生产方声称其产品的质量水平达到了某个标准（如不合格品率不超过 $p_0$），检验方通过抽样检测来判断这一声称是否可信。

### 基本思想

与 NC 抽样法"同时控制生产方和使用方双方风险"不同，DQL 检验的核心是**单侧假设检验**——只关心质量是否**低于**声称水平，不涉及使用方风险的控制。

### 数学模型

#### 1. 假设设定

设批不合格品率为 $p$，建立假设：

$$
H_0: p \leq p_0 \quad (\text{质量达到或优于声称水平，接受该批}) \\
H_1: p > p_0 \quad (\text{质量未达到声称水平，拒收该批})
$$

其中 $p_0$ 为**声称质量水平**（Declared Quality Level），即生产方宣称的不合格品率上限。

> **注意：** 这是一个**单侧检验**。$H_0$ 和 $H_1$ 的关注点只有一个方向——质量是否"差于"声称。

#### 2. 检验统计量

从批中抽取 $n$ 个样品，设不合格品数为 $d$，样本不合格品率为 $\hat{p} = d/n$。

**精确方法（二项分布）：**

当原假设 $H_0$ 成立（$p = p_0$）时，$d$ 服从二项分布 $B(n, p_0)$。检验的 $p$ 值为：

$$
p\text{-value} = P(D \geq d \;|\; H_0) = \sum_{k=d}^{n} \binom{n}{k} p_0^k (1-p_0)^{n-k}
$$

**近似方法（正态分布，当 $n$ 较大时）：**

根据中心极限定理，当 $n$ 足够大时（$np_0 \geq 5$ 且 $n(1-p_0) \geq 5$）：

$$
Z = \frac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}} \xrightarrow{d} N(0,1)
$$

检验统计量为：

$$
Z = \frac{d/n - p_0{\sqrt{p_0(1-p_0)/n}}}
$$

#### 3. 判定规则

给定显著性水平 $\alpha$（通常取 0.05），查标准正态分布临界值 $Z_\alpha$：

$$


\begin{cases}
Z \leq Z_\alpha \; (\text{或 } p\text{-value} \geq \alpha) & \Rightarrow \text{不能拒绝 } H_0 \text{，认为质量达到声称水平} \\
Z > Z_\alpha \; (\text{或 } p\text{-value} < \alpha) & \Rightarrow \text{拒绝 } H_0 \text{，认为质量未达到声称水平}
\end{cases}
}
$$

### 与 NC 抽样法的关系

理解 DQL 检验与 NC 抽样法的区别至关重要：

| 方面 | NC 抽样法 | DQL 检验 |
|------|----------|----------|
| 风险控制 | 同时控制 $\alpha$（生产方风险）和 $\beta$（使用方风险） | **仅控制 $\alpha$**（生产方风险） |
| 决策框架 | 抽样验收方案 | 统计假设检验 |
| 参数 | $p_0, p_1, \alpha, \beta$ | $p_0, \alpha$（需额外设定 $n$） |
| 适用场景 | 供需双方约定的验收 | 单方面验证声称质量 |

DQL 检验可以视为 NC 抽样法在**不考虑使用方风险（即 $\beta$ 无要求）** 时的简化版本——此时 $c$ 的选取只需满足当 $p = p_0$ 时接收概率为 $1-\alpha$ 即可。

### 检验功效与样本量

检验功效（Power）指当 $p$ 确实大于 $p_0$ 时，检验能正确拒绝 $H_0$ 的概率。对于给定的 $p_1$（实际的不合格率），功效为：

$$
\text{Power}(p_1) = P(\text{拒绝 } H_0 \;|\; p = p_1)
$$

要达到一定的功效 $1-\beta$，所需样本量为：

$$
n = \left( \frac{Z_\alpha \sqrt{p_0(1-p_0) + Z_\beta \sqrt{p_1(1-p_1)}}{p_1 - p_0} \right)^2}
$$

其中 $Z_\alpha$ 和 $Z_\beta$ 分别为标准正态分布的 $\alpha$ 和 $\beta$ 分位数，$p_1$ 是需要被有效检测出的不合格品率。

## 🎯 适用场景

| 适用问题类型 | 具体例子 |
|-------------|---------|
| **供应商声称的验证** | 供应商声称不合格率 ≤ 1%，入场时抽样验证 |
| **企业内部质量审核** | 检验本厂某工序是否达到宣称的 99.5% 合格率 |
| **市场监管抽检** | 质监局对某品牌产品的质量声称进行抽查 |
| **产品标签合规检验** | 验证产品实际质量是否符合标签上的声称 |
| **单方质量评估** | 买方在无供方配合时独立进行的质量判断 |

**数据要求：**
- **数据类型：** 二值计数数据（合格/不合格），或可转化为二值
- **数据量要求：** 正态近似法要求 $np_0 \geq 5$ 且 $n(1-p_0) \geq 5$
- **前提假设：**
  - 抽样为简单随机抽样
  - 各样品质量独立
  - $p_0$ 由生产方声称，合理且真实

## 📋 详细算法步骤

### 步骤 1：明确声称质量水平

确定 $p_0$，即生产方声称的不合格品率上限（或合格率下限）。例如："本批次产品不合格品率不超过 2%"。

### 步骤 2：设定显著性水平

选择 $\alpha$ 值，通常取 0.05 或 0.01。$\alpha$ 的意义是：当质量确实达到声称水平时，错误拒绝（冤枉好批）的概率。

### 步骤 3：确定样本量

有两种情况：

**情况 A：样本量由外部限定（如抽检经费、时间限制）**
直接使用给定的 $n$，后续判断检验功效是否足够。

**情况 B：自由设计样本量**

使用功效公式计算：

$$
n = \left( \frac{Z_\alpha \sqrt{p_0(1-p_0)} + Z_\beta \sqrt{p_1(1-p_1)}}{p_1 - p_0} \right)^2
$$

其中 $p_1$ 是"我们希望有多大把握检测出的不合格品率"，$1-\beta$ 为目标功效。

> **示例：** 若 $p_0 = 0.02$，希望以 90% 的功效检测出 $p_1 = 0.05$ 的劣质批，取 $\alpha=0.05$：
> $$
> n = \left( \frac{1.645 \times \sqrt{0.02\times0.98} + 1.282 \times \sqrt{0.05\times0.95}}{0.05 - 0.02} \right)^2 \approx 278
> $$

### 步骤 4：实施抽样检测

随机抽取 $n$ 个样品进行质量检验，记录不合格品数 $d$。

### 步骤 5：计算检验统计量

**二项精确法（推荐）：**

$$
p\text{-value} = \sum_{k=d}^{n} \binom{n}{k} p_0^k (1-p_0)^{n-k}
$$

**正态近似法（大样本）：**

$$
Z = \frac{d/n - p_0}{\sqrt{p_0(1-p_0)/n}}
$$

### 步骤 6：做出判定

比较 $p$-value 与 $\alpha$（或 $Z$ 与 $Z_\alpha$）：

- $p\text{-value} \geq \alpha$ → 无充分证据拒绝声称，认为质量达标
- $p\text{-value} < \alpha$ → 有充分证据拒绝声称，认为质量未达标

### 步骤 7：计算置信区间（可选但推荐）

报告样本不合格品率的 $1-\alpha$ 置信上限，比单纯的"拒绝/不拒绝"结论提供更多信息：

$$
\hat{p} \text{ 的置信上限: } \bar{p} = \hat{p} + Z_{\alpha} \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}
$$

若 $\bar{p} < p_0$，则更确信质量达标；若 $\bar{p} > p_0$，则质量可能接近临界。

---

## ⚖️ 优缺点

| ✅ 优点 | ❌ 缺点 |
|--------|--------|
| 统计理论基础扎实，$p$ 值提供定量证据强度 | **未控制使用方风险（$\beta$）**：当样本量不足时，可能无法有效检出质量不合格的批次 |
| 操作流程简单，仅需 $p_0$ 和 $\alpha$ | 样本量需要预先确定，不够灵活 |
| 可计算检验功效，评价方案的检测能力 | 对小样本需用精确二项检验，正态近似可能失真 |
| $p$ 值和置信区间提供比"合格/不合格"更丰富的信息 | 不区分"优秀批"和"合格批"——只要通过检验即视为合格 |
| 与其他统计软件和分析工具兼容性好 | 单纯依赖该方法可能导致使用方承担过度风险 |

## 💻 使用方法 (Python)

### 1. 核心检验函数

```python
import numpy as np
from scipy.stats import binom, norm

def dql_test(n, d, p0, alpha=0.05, method='exact'):
    """
    声称质量水平 (DQL) 检验
    
    参数:
        n: 样本量
        d: 不合格品数
        p0: 声称的不合格品率上限
        alpha: 显著性水平
        method: 'exact' (精确二项) 或 'normal' (正态近似)
    
    返回:
        dict: 包含检验结果的各种统计量
    """
    p_hat = d / n  # 样本不合格品率
    
    # ---------- 精确二项检验 ----------
    # P(D >= d | p0) 右尾概率
    p_value_exact = 1 - binom.cdf(d - 1, n, p0)
    
    # ---------- 正态近似检验 ----------
    se = np.sqrt(p0 * (1 - p0) / n)
    Z = (p_hat - p0) / se
    p_value_norm = 1 - norm.cdf(Z)
    
    # ---------- 结论 ----------
    if method == 'exact':
        reject = p_value_exact < alpha
        p_value = p_value_exact
    else:
        reject = p_value_norm < alpha
        p_value = p_value_norm
    
    # ---------- 置信区间 ----------
    # 单侧置信上限（Wald 法）
    z_alpha = norm.ppf(1 - alpha)
    ci_upper = p_hat + z_alpha * np.sqrt(p_hat * (1 - p_hat) / n)
    
    # ---------- 功效分析 ----------
    def power_at(p1):
        """计算在给定真实不合格率 p1 下的检验功效"""
        n_sim = 10000
        reject_count = 0
        for _ in range(n_sim):
            d_sim = np.random.binomial(n, p1)
            pv = 1 - binom.cdf(d_sim - 1, n, p0)
            if pv < alpha:
                reject_count += 1
        return reject_count / n_sim
    
    return {
        'n': n,
        'd': d,
        'p_hat': p_hat,
        'p0': p0,
        'Z_stat': Z,
        'p_value_exact': p_value_exact,
        'p_value_norm': p_value_norm,
        'p_value': p_value,
        'method': method,
        'reject': reject,
        'ci_upper_95': ci_upper,
        'conclusion': '❌ 拒绝声称（质量未达标）' if reject else '✅ 无法拒绝声称（质量达标）',
        'interpretation': (
            f"抽样 {n} 个，发现 {d} 个不合格 (≈{p_hat*100:.1f}%)。"
            f"声称质量水平为 {p0*100:.1f}%。"
            f"检验 p 值={p_value:.4f}{'' if reject else '>'}{'<' if reject else ''}{alpha}，"
            f"{'有' if reject else '无'}充分证据拒绝生产方的声称质量。"
        )
    }

# 示例使用
result = dql_test(n=300, d=4, p0=0.02, alpha=0.05, method='exact')
print(result['conclusion'])
print(result['interpretation'])
print(f"p值(精确): {result['p_value_exact']:.4f}")
```

### 2. 样本量计算

```python
def required_sample_size(p0, p1, alpha=0.05, beta=0.20):
    """
    计算达到指定检验功效所需的最小样本量
    
    参数:
        p0: 声称质量水平 (H0)
        p1: 需要检测出的不合格品率
        alpha: 显著性水平
        beta: 使用方风险 (功效 = 1-beta)
    
    返回:
        int: 所需最小样本量
    """
    z_alpha = norm.ppf(1 - alpha)
    z_beta = norm.ppf(1 - beta)
    
    numerator = z_alpha * np.sqrt(p0 * (1 - p0)) + z_beta * np.sqrt(p1 * (1 - p1))
    denominator = p1 - p0
    
    n = (numerator / denominator) ** 2
    return int(np.ceil(n))

# 示例
p0, p1 = 0.02, 0.05
for beta in [0.20, 0.10, 0.05]:
    n = required_sample_size(p0, p1, alpha=0.05, beta=beta)
    print(f"功效={(1-beta)*100:.0f}% 时，所需样本量 n={n}")
```

### 3. 完整的工作流示例

```python
def dql_workflow(N, p0_claimed, alpha=0.05, beta=0.20, detect_ratio=2.5):
    """
    完整的声称质量水平检验工作流
    
    参数:
        N: 批量
        p0_claimed: 声称的不合格率
        detect_ratio: 希望检测出的 p1 = p0 * detect_ratio
    
    返回:
        打印完整的检验方案
    """
    p1 = p0_claimed * detect_ratio
    
    print("=" * 50)
    print("📋 声称质量水平检验方案设计")
    print("=" * 50)
    print(f"批量 N = {N}")
    print(f"声称质量水平 p0 = {p0_claimed*100:.2f}%")
    print(f"需检测出的水平 p1 = {p1*100:.2f}% (p0 × {detect_ratio})")
    print(f"显著性水平 α = {alpha}")
    print(f"目标功效 1-β = {(1-beta)*100:.0f}%")
    print()
    
    # 计算样本量
    n = required_sample_size(p0_claimed, p1, alpha, beta)
    print(f"👉 建议样本量 n = {n}")
    
    # 计算临界不合格数
    # 找到最小的 c 使得 P(D >= c | p0) <= alpha
    for c in range(0, n + 1):
        p_val = 1 - binom.cdf(c - 1, n, p0_claimed)
        if p_val <= alpha:
            print(f"👉 临界不合格数 c = {c} (当 d ≥ {c} 时拒绝声称)")
            break
    
    # 实际功效
    power = 1 - binom.cdf(c - 1, n, p1)
    print(f"👉 实际检验功效 = {power*100:.1f}%")
    
    print()
    print("判定规则:")
    print(f"  抽检 {n} 个样品:")
    print(f"    - 不合格数 < {c}: 质量达到声称水平 ✅")
    print(f"    - 不合格数 ≥ {c}: 质量未达到声称水平 ❌")
    
    return n, c

# 示例
dql_workflow(N=5000, p0_claimed=0.02, alpha=0.05, beta=0.20)
```

## 📊 实例应用

### 实例 1：供应商声称验证

某供应商声称其产品不合格品率不超过 2%（$p_0 = 0.02$）。采购方抽检了 200 个样品，发现 6 个不合格品。

**检验过程：**

$$
\begin{aligned}
\hat{p} &= 6/200 = 0.03 \\
Z &= \frac{0.03 - 0.02}{\sqrt{0.02 \times 0.98 / 200}} = \frac{0.01}{0.0099} \approx 1.01 \\
p\text{-value} &= P(Z > 1.01) \approx 0.156 > 0.05
\end{aligned}
$$

**结论：** 无充分证据拒绝声称，认为质量达标。

### 实例 2：功效 vs 样本量的权衡

假设 $p_0 = 0.02$，$\alpha = 0.05$：

| 目标 $p_1$ | 功效 80% 所需 $n$ | 功效 90% 所需 $n$ | 功效 95% 所需 $n$ |
|-----------|-------------------|-------------------|-------------------|
| 0.03 | 1550 | 2050 | 2540 |
| 0.04 | 430 | 575 | 715 |
| 0.05 | 210 | 280 | 350 |
| 0.08 | 70 | 95 | 118 |

可见，若 $p_1$ 与 $p_0$ 非常接近（如 0.02 vs 0.03），需要极大的样本量才能可靠检测出差异。这在实际中往往不可行，因此 DQL 检验更适合 $p_1/p_0 \geq 2$ 的场景。

### 实例 3：与 NC 抽样法的对比

给定 $p_0 = 0.02$，$\alpha = 0.05$：

- **DQL 检验**（仅控制 $\alpha$）：$n=200$ 时，不合格数 $\geq 8$ 才拒绝声称
- **NC 抽样法**（控制 $\alpha$ 和 $\beta=0.10$，$p_1=0.05$）：$n=200$，$c=7$

对比发现，对于同样的 $n$，DQL 的 $c$ 值略大于 NC 法的 $c$ 值，因为 DQL 只需要控制 $\alpha$、不需要控制 $\beta$，判定标准略宽松。

## 🔗 关联算法

- [[NC抽样法]] — 同时控制 $\alpha$ 和 $\beta$ 的双侧抽样方案，与 DQL 检验形成对比
- [[序贯概率比检验法 (SPRT)]] — 序贯版本的假设检验，同样基于似然比，但样本量不固定

- **Fisher 精确检验** — 适用于小样本的比例检验替代方法

## 📝 补充说明

### 关于声称质量水平 (DQL)

"声称质量水平"（Declared Quality Level）在不同标准中有不同定义：
- 在 ISO 2859 / GB/T 2828 体系中，DQL 通常指生产方在合同或标签上声明的质量水平
- 在一些场景中，DQL 等价于 AQL（合格质量水平），但 DQL 更强调"单方声明"而非"双方约定"

### 实际应用注意事项

1. **统计显著性与实际显著性**：$p$ 值 $< 0.05$ 只说明有统计证据表明质量低于声称，但不一定意味着差距有实际意义。应同时报告 $\hat{p}$ 和置信区间。
2. **样本量不足的风险**：若 $n$ 过小，即使质量远低于声称水平也可能无法检出（功效不足），导致使用方承担风险。
3. **多次检验的累积错误**：若频繁对同一供方做 DQL 检验，应考虑多重比较校正（如 Bonferroni 校正）。
4. **推荐做法**：报告 DQL 检验结果时，同时提供 $p$ 值、$\hat{p}$ 的置信区间和检验功效，以便读者全面评估。
