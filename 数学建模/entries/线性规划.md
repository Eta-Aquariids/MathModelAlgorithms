## 📖 算法原理

**线性规划（Linear Programming, LP）** 是数学规划中最基本、应用最广泛的分支，研究在**线性约束**下对**线性目标函数**进行优化的问题。由 George Dantzig 于 1947 年提出，是运筹学的基石。

### 标准形式

$$
\boxed{\begin{aligned}
\min \quad & \mathbf{c}^T \mathbf{x} \\
\text{s.t.} \quad & A\mathbf{x} \leq \mathbf{b} \\
& \mathbf{x} \geq \mathbf{0}
\end{aligned}}
$$

其中：
- $\mathbf{x} \in \mathbb{R}^n$：决策变量向量
- $\mathbf{c} \in \mathbb{R}^n$：目标函数系数向量
- $A \in \mathbb{R}^{m \times n}$：约束条件系数矩阵
- $\mathbf{b} \in \mathbb{R}^m$：约束右端项向量

### 几何意义

- 可行域是一个**凸多面体**（所有约束的交集）
- 最优解一定出现在可行域的**顶点（极点）**上
- 因此理论上只需在有限个顶点中搜索

### 单纯形法核心思想

从可行域的一个顶点出发，沿着棱边移动到相邻的、使目标函数值更优的另一个顶点，直到找到最优解。

### 对偶理论

每个 LP 问题都有一个对应的**对偶问题**。原问题与对偶问题之间有深刻的关系：

| 原问题 | 对偶问题 |
|--------|---------|
| $\min \mathbf{c}^T\mathbf{x}$ | $\max \mathbf{b}^T\mathbf{y}$ |
| $A\mathbf{x} \geq \mathbf{b}$ | $A^T\mathbf{y} \leq \mathbf{c}$ |
| $\mathbf{x} \geq \mathbf{0}$ | $\mathbf{y} \geq \mathbf{0}$ |

**弱对偶定理：** 原问题任意可行解的目标值 ≥ 对偶问题任意可行解的目标值
**强对偶定理：** 若原问题有最优解，则对偶问题也有最优解，且两者相等

## 🎯 适用场景

| 问题类型 | 具体例子 |
|---------|---------|
| 生产计划 | 有限资源下多种产品的产量安排 |
| 运输问题 | 多个供应点到多个需求点的调运方案 |
| 投资组合 | 有限资金下各资产配置比例优化 |
| 人员排班 | 最小化人力成本的同时满足岗位需求 |
| 混合配方 | 原材料配比使成本最低且满足成分要求 |

**数据要求：**
- 目标函数和约束条件**必须都为线性**
- 决策变量连续（若不是，则为整数规划）
- 问题规模：单纯形法可处理百万级变量

---

## 📋 算法步骤（单纯形法）

1. **标准化：** 将问题转化为标准形式（引入松弛变量）
2. **找初始基可行解：** 通常在原点或通过人工变量法
3. **最优性检验：** 检验当前基可行解是否为最优（检验数是否全部 ≥ 0）
4. **进基：** 选择检验数为负且绝对值最大的非基变量
5. **出基：** 按最小比值规则确定离基变量
6. **旋转：** 通过初等行变换更新表格，得到新的基可行解
7. **重复 3~6** 直到找到最优解

### 内点法（大规模问题）

对于超大规模 LP（变量 > 百万级），内点法比单纯形法更快——从可行域内部沿最速下降方向逼近最优解。

---

## ⚖️ 优缺点

| ✅ 优点 | ❌ 缺点 |
|--------|--------|
| 理论完备，有全局最优解保证 | 只能处理线性关系，不能表示非线性 |
| 求解效率高（可解百万级变量） | 离散决策需整数规划，求解难度剧增 |
| 成熟软件多（CPLEX, Gurobi, scipy） | 对数据精度敏感，病态条件可能不稳定 |
| 敏感性分析完善 | 不适用于随机/模糊参数 |

## 💻 使用方法 (Python)

```python
from scipy.optimize import linprog
import numpy as np

# 例：max Z = 3x1 + 2x2
# 约束: x1 + x2 ≤ 4, 2x1 + x2 ≤ 6, x1, x2 ≥ 0

c = [-3, -2]  # 取负号转为极小化
A = [[1, 1],
     [2, 1]]
b = [4, 6]
bounds = [(0, None), (0, None)]

res = linprog(c, A_ub=A, b_ub=b, bounds=bounds, method='highs')
print(f"最优值: {-res.fun:.2f}")    # 恢复极大化符号
print(f"最优解: x1={res.x[0]:.2f}, x2={res.x[1]:.2f}")
```

## 🔗 关联算法

- [[整数规划 (IP)]] — LP 的扩展，要求部分或全部变量为整数
- [[非线性规划 (NLP)]] — 目标或约束为非线性的推广
- [[动态规划 (DP)]] — 分阶段决策的另一种优化范式

## 📝 补充说明

- LP 可用 **Python pulp / cvxpy** 或专业求解器 **Gurobi / CPLEX** 高效求解
- 数学建模中常用 LP 做**资源分配框架**，再扩展为整数规划或随机规划
