## 📖 算法原理

**整数规划（Integer Programming, IP）** 是线性规划的扩展，要求部分或全部决策变量取整数。当变量表示人数、机器数量、是否决策等离散量时，整数规划是必然选择。

### 分类

| 类型 | 说明 | 例子 |
|------|------|------|
| **纯整数规划** | 所有变量均为整数 | 整数生产数量 |
| **混合整数规划 (MIP)** | 部分变量连续，部分整数 | 连续产量 + 0-1开关决策 |
| **0-1 整数规划** | 变量取值 0 或 1 | 选址问题、指派问题 |

### 为什么整数规划比 LP 难得多？

LP 的可行域是凸集，最优解在顶点；而整数规划的可行域是**离散的点集**，不连续：

- 单纯舍入 LP 解通常**不可行**或**非最优**
- 理论上 IP 是 **NP-hard** 问题（除特殊结构外）
- 求解时间随变量个数**指数增长**

### 求解方法

#### 1. 分支定界法 (Branch and Bound)

最核心的 IP 求解方法：

1. **松弛：** 先忽略整数约束，求解对应的 LP（称为 LP 松弛）
2. **分支：** 若某个变量 $x_j$ 的松弛解为 $3.4$，则创建两个子问题：$x_j \leq 3$ 和 $x_j \geq 4$
3. **定界：** 计算每个子问题的 LP 松弛解，作为该分支的下界
4. **剪枝：** 若某分支的下界 > 当前最优整数解，则无需继续搜索
5. **重复**直到所有分支搜索完毕

#### 2. 割平面法 (Cutting Planes)

通过添加约束（割平面）逐步切除 LP 可行域中不含整数点的部分，使最优解自然成为整数点。

**Gomory 割平面：** 从单纯形表中直接推导出有效的割平面约束。

#### 3. 现代求解器策略

现代求解器（Gurobi, CPLEX）通常采用**分支切割法**（Branch and Cut）= 分支定界 + 割平面 + 启发式方法。

## 🎯 适用场景

| 问题类型 | 具体例子 |
|---------|---------|
| 选址问题 | n 个候选点选 k 个建仓库，使运输成本最小 |
| 指派问题 | m 个人分配 n 个任务，追求总效率最大 |
| 背包问题 | 有限容量下选择物品组合使价值最大 |
| 生产调度 | 机器排产、订单排序中的离散决策 |
| 投资决策 | 项目选投（每个项目投/不投，0-1 变量） |

**数据要求：**
- 整数变量规模是关键限制（纯 IP 建议整数变量 ≤ 几百个）
- 0-1 变量的 MIP 可通过商业求解器处理上万变量

## 💻 使用方法 (Python)

```python
from scipy.optimize import milp, Bounds, LinearConstraint
import numpy as np

# 例：max Z = 3x1 + 2x2
# x1 + x2 ≤ 4, 2x1 + x2 ≤ 6
# x1, x2 ≥ 0 且为整数

c = -np.array([3, 2])  # 极小化形式
A = np.array([[1, 1],
              [2, 1]])
b = np.array([4, 6])

constraints = LinearConstraint(A, -np.inf, b)
bounds = Bounds(0, np.inf)
integrality = [1, 1]  # 1=整数, 0=连续

res = milp(c=c, constraints=constraints, 
           bounds=bounds, integrality=integrality)
print(f"最优值: {-res.fun:.2f}")
print(f"最优解: x1={res.x[0]:.0f}, x2={res.x[1]:.0f}")
```

## ⚖️ 优缺点

| ✅ 优点 | ❌ 缺点 |
|--------|--------|
| 表达能力强——0-1 变量可表示逻辑决策 | 计算复杂度高（NP-hard） |
| 贴近实际问题（离散决策天然存在） | 变量增多时求解时间指数增长 |
| 有成熟的商业求解器 | 小问题可能也需很长求解时间 |

## 🔗 关联算法

- [[线性规划 (LP)]] — 整数规划的理论基础，求解 IP 的核心子过程
- [[动态规划 (DP)]] — 某些 IP 问题（如背包）可用 DP 高效求解
- [[模拟退火算法 (SA)]] — 大规模 IP 问题可用启发式方法近似求解
- [[粒子群算法 (PSO)]] — 可结合 0-1 编码求解组合优化

## 📝 补充说明

- 数学建模中，**0-1 变量 + 连续变量**的混合整数规划是应用最多的形式
- 常见技巧：用 0-1 变量表示"选择/不选择"、"开启/关闭"等逻辑关系
- 数据规模较大时，可先用 SA/PSO 等智能算法求近似解
