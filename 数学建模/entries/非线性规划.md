## 📖 算法原理

**非线性规划（Nonlinear Programming, NLP）** 指目标函数或约束条件中含有非线性成分的优化问题。现实世界中的大多数优化问题本质上都是非线性的。

### 一般形式

$$\min f(\mathbf{x})$$

$$\text{s.t. } g_i(\mathbf{x}) \leq 0, \quad i = 1, \ldots, m$$

$$h_j(\mathbf{x}) = 0, \quad j = 1, \ldots, p, \quad \mathbf{x} \in \mathbb{R}^n$$

其中 $f(\mathbf{x})$、$g_i(\mathbf{x})$、$h_j(\mathbf{x})$ 至少有一个为非线性函数。

### 凸优化 vs 非凸优化

| 性质 | 凸优化 | 非凸优化 |
|------|-------|---------|
| 目标函数 | 凸函数 | 非凸函数 |
| 可行域 | 凸集 | 非凸集 |
| 最优解 | **任何局部最优 = 全局最优** | 局部最优 ≠ 全局最优 |
| 求解难度 | 容易（可精确求解） | 困难（NP-hard） |

### 核心求解方法

#### 1. 无约束优化

**梯度下降法（最速下降法）：**

$$\mathbf{x}^{(k+1)} = \mathbf{x}^{(k)} - \alpha \nabla f(\mathbf{x}^{(k)})$$

- $\alpha$：步长（学习率），可通过线搜索确定
- 方向：负梯度方向（函数值下降最快的方向）

**牛顿法：**

$$\mathbf{x}^{(k+1)} = \mathbf{x}^{(k)} - \left[ \nabla^2 f(\mathbf{x}^{(k)}) \right]^{-1} \nabla f(\mathbf{x}^{(k)})$$

利用二阶导数（Hessian 矩阵），收敛更快但计算量大。

#### 2. KKT 条件（约束优化）

对于带约束的 NLP，最优解必须满足 **KKT 条件**：

$$\nabla f(\mathbf{x}^*) + \sum_{i=1}^m \mu_i \nabla g_i(\mathbf{x}^*) + \sum_{j=1}^p \lambda_j \nabla h_j(\mathbf{x}^*) = 0$$

$$\mu_i \geq 0, \quad \mu_i g_i(\mathbf{x}^*) = 0, \quad i = 1, \ldots, m$$

$$g_i(\mathbf{x}^*) \leq 0, \quad h_j(\mathbf{x}^*) = 0$$

其中 $\mu_i$、$\lambda_j$ 称为**拉格朗日乘子**。KKT 条件在凸优化中既是必要的也是充分的。

#### 3. 常用求解算法

| 算法 | 适用场景 | 特点 |
|------|---------|------|
| **序列二次规划 (SQP)** | 中小规模 NLP | NLP → 系列 QP 子问题，精度高 |
| **内点法** | 大规模 NLP | 从可行域内部逼近 |
| **增广拉格朗日法** | 约束优化 | 将约束融入目标，转为无约束 |
| **遗传/粒子群** | 非凸 NLP | 不保证最优，但能处理任意形式 |

## 🎯 适用场景

| 问题类型 | 具体例子 |
|---------|---------|
| 曲线拟合 | 最小二乘法、非线性回归参数估计 |
| 机械设计 | 重量最小化下满足强度约束的结构参数优化 |
| 经济均衡 | 效用最大化、利润最大化 |
| 神经网络训练 | 损失函数最小化（非凸高维优化） |
| 工程反问题 | 从观测数据反推模型参数 |

**数据要求：**
- 目标函数和约束至少有一个为非线性
- 对可微性、凸性的要求取决于所选算法

---

## 📋 详细算法步骤

1. **建模：** 写出目标函数和约束条件
2. **判断凸性：** 若为凸优化，可精确求解
3. **选择算法：** 根据问题规模和凸性选择合适的求解器
4. **设定初值：** 非凸问题对初值敏感，可尝试多组初始点
5. **求解：** 调用求解器
6. **验证：** 检查 KKT 条件是否满足

---

## ⚖️ 优缺点

| ✅ 优点 | ❌ 缺点 |
|--------|--------|
| 表达能力强——可建模真实世界的非线性关系 | 非凸问题时只能找到局部最优 |
| 凸优化有全局最优的理论保证 | 对初始点敏感（非凸问题） |
| 连续可微时可利用梯度高效求解 | 大规模时 Hessian 计算困难 |

## 💻 使用方法 (Python)

```python
from scipy.optimize import minimize


def objective(x):
    return x[0]**2 + x[1]**2 + 2*x[0] + 4*x[1]


constraints = [
    {'type': 'ineq', 'fun': lambda x: x[0] + x[1] - 2}
]

res = minimize(objective, x0=[0, 0], method='SLSQP', constraints=constraints)
print(f"最优值: {res.fun:.4f}")
print(f"最优解: x1={res.x[0]:.4f}, x2={res.x[1]:.4f}")
```

## 🔗 关联算法

- [[线性规划 (LP)]] — NLP 在线性情形下的特例
- [[整数规划 (IP)]] — NLP 在整数约束下的推广（MINLP，极难求解）
- [[模拟退火算法 (SA)]] — 可求解非凸 NLP，不依赖梯度
- [[粒子群算法 (PSO)]] — 可求解非凸 NLP，适合多峰函数

## 📝 补充说明

- 数学建模中，如果问题可以被建模为凸优化，优先选择凸优化（最优性有保证）
- 遇到非凸问题时，可用 SA/PSO 求近似解，或多次运行梯度法取最优
- 推荐求解器：cvxpy（凸优化）、scipy.optimize（中等规模）、Gurobi（可解二次规划）
