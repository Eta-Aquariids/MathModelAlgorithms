## 📖 算法原理

**多目标优化** 处理**多个目标同时需要优化**的问题，目标之间往往相互矛盾，只能找到一组 **Pareto 最优解**。

### 核心概念

**Pareto 最优：** 不存在一个解在所有目标上都优于 Pareto 最优解，Pareto 前沿即所有这些解的集合。

数学模型：

$$
\min \quad F(\mathbf{x}) = (f_1(\mathbf{x}), f_2(\mathbf{x}), \ldots, f_k(\mathbf{x}))
$$

$$
\text{s.t.} \quad g_i(\mathbf{x}) \leq 0, \quad i=1,\ldots,m
$$

### 三种主要方法

**1. 加权求和法：**

$$
\min \sum_{i=1}^{k} w_i f_i(\mathbf{x}), \quad \sum w_i = 1
$$

简单直观，调整权重得到不同 Pareto 解，但无法得到非凸前沿上的点。

**2. ε-约束法：** 保留一个目标，其余转化为约束：

$$
\min f_1(\mathbf{x}) \quad \text{s.t.} \quad f_j(\mathbf{x}) \leq \varepsilon_j
$$

**3. NSGA-II（最常用）：**

- 非支配排序：将种群分层，每层为一个 Pareto 面
- 拥挤距离：同一层内维持多样性
- 选择 + 交叉变异 → 重复

## 💻 使用方法 (Python)

### 加权法

```python
from scipy.optimize import minimize

objectives = [lambda x: x[0]**2, lambda x: (x[0]-2)**2]
best = minimize(lambda x: 0.5*objectives[0](x) + 0.5*objectives[1](x), [0], bounds=[(-10,10)])
print(f"x={best.x[0]:.3f}, f1={best.fun:.3f}")
```

### NSGA-II 框架（基于 DEAP 库）

```python
from deap import base, creator, tools, algorithms
import random

creator.create("FitnessMulti", base.Fitness, weights=(-1.0, -1.0))
creator.create("Individual", list, fitness=creator.FitnessMulti)

def evaluate(ind):
    return ind[0]**2, (ind[0]-2)**2

toolbox = base.Toolbox()
toolbox.register("attr_float", random.uniform, -10, 10)
toolbox.register("individual", tools.initRepeat, creator.Individual, toolbox.attr_float, n=1)
toolbox.register("population", tools.initRepeat, list, toolbox.individual)
toolbox.register("evaluate", evaluate)
toolbox.register("mate", tools.cxBlend, alpha=0.5)
toolbox.register("mutate", tools.mutGaussian, mu=0, sigma=1, indpb=0.2)
toolbox.register("select", tools.selNSGA2)

pop = toolbox.population(n=100)
result, _ = algorithms.eaMuPlusLambda(pop, toolbox, 100, 20, 50)
front = tools.sortNondominated(result, len(result), first_front_only=True)[0]
print(f"Pareto 前沿解数: {len(front)}")
```

## ⚖️ 优缺点

| 方法 | 优点 | 缺点 |
|------|------|------|
| **加权法** | 实现简单，兼容已有求解器 | 权重主观，无法处理非凸前沿 |
| **ε-约束法** | 能处理非凸问题 | 需要知道目标范围 |
| **NSGA-II** | 一次性得到一组前沿解，分布均匀 | 计算量大，需调参 |
