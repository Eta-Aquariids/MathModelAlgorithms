## 📖 算法原理

**模拟退火算法（Simulated Annealing, SA）** 是一种受**金属退火**物理过程启发的随机优化算法。1983 年由 Kirkpatrick、Gelatt 和 Vecchi 首次提出，是元启发式算法的开创性工作之一。

### 物理类比

在金属冶炼中，退火过程分为三个阶段：
1. **加热**：将金属加热到高温，粒子获得高能量，活动剧烈
2. **缓慢降温**：温度逐渐降低，粒子热运动减缓，逐渐趋于有序排列
3. **冷却**：到达低温时，粒子排列成能量最低的晶体结构（全局最优解）

模拟退火算法将这一过程映射到优化问题中：
- **解空间** → 物理系统的状态空间
- **目标函数 $f(x)$** → 系统的能量 $E$
- **温度 $T$** → 控制参数，决定算法接收"差解"的概率
- **最优解** → 能量最低的基态

### 核心机制：Metropolis 准则

SA 的核心是 **Metropolis 准则**——以一定概率接受比当前解更差的解，从而让算法有机会跳出局部最优。

设当前解为 $x$，目标函数值为 $f(x)$，新解为 $x'$，目标函数值为 $f(x')$：

$$
\Delta E = f(x') - f(x)
$$

- **如果 $\Delta E < 0$**（新解更好）：**一定接受** $x'$
- **如果 $\Delta E \geq 0$**（新解更差）：以 **概率** $P$ 接受 $x'$

接受概率由 **Boltzmann 分布** 决定：

$$
P(\text{接受) = \exp\left(-\frac{\Delta E}{T}\right)}
$$

其中 $T$ 为当前温度。分析这个公式：

| 情形 | $\Delta E$ | $T$ | 接受概率 | 含义 |
|------|-----------|-----|---------|------|
| 新解略差 | 小正数 | 高 | 接近 1 | 高温时广泛探索 |
| 新解略差 | 小正数 | 低 | 较小 | 低温时趋于保守 |
| 新解很差 | 大正数 | 高 | 较小 | 即使高温也不太接受极差解 |
| 新解很差 | 大正数 | 低 | 趋近 0 | 低温时几乎不接收差解 |

### 温度与冷却

$T$ 从初始高温 $T_0$ 开始，随着迭代逐渐降低。常见的降温方式：

**指数降温（最常用）：**

$$
T_{k+1} = \alpha \cdot T_k, \quad \alpha \in (0.8, 0.99)
$$

**线性降温：**

$$
T_{k+1} = T_k - \Delta T
$$

**对数降温（理论收敛保证）：**

$$
T_k = \frac{T_0}{\ln(k + 2)}
$$

> 理论上，对数降温可以保证以概率 1 收敛到全局最优，但实际运算中需要极长的迭代次数，通常使用指数降温。

## 🎯 适用场景

| 适用问题类型 | 具体例子 |
|-------------|---------|
| **组合优化问题** | TSP 旅行商问题、背包问题、图着色问题 |
| **连续函数全局优化** | 多峰函数的全局最小值搜索 |

**数据要求：**
- **数据类型：** 适用于任意形式的目标函数（离散/连续、可微/不可微）
- **核心要求：** 必须能定义"邻域结构"——即从当前解如何生成新解
- **前提假设：** 无特殊假设（不要求凸性、可微性或连续性）

## 📋 详细算法步骤

### 算法流程

```
输入: 目标函数 f(x), 解空间 S
参数: 初始温度 T₀, 终止温度 T_min, 冷却率 α, 每温度迭代次数 L

1.  生成初始解 x ∈ S, 计算 f(x)
2.  设当前温度 T = T₀
3.  WHILE T > T_min:
4.      FOR i = 1 TO L:
5.          从当前解 x 的邻域生成新解 x'
6.          计算 ΔE = f(x') - f(x)
7.          IF ΔE < 0:          # 新解更好
8.              x = x'          # 直接接受
9.          ELSE:               # 新解更差
10.             p = exp(-ΔE / T)
11.             IF random(0,1) < p:
12.                 x = x'      # 概率接受
13.     T = α × T               # 降温
14. RETURN x 及 f(x)
```

### 关键设计要素

#### 1. 初始解生成
- 可随机生成，也可用贪心法生成一个较优的初始解（加速收敛）
- 对 TSP 可用最近邻法，对连续优化可随机采样

#### 2. 邻域结构（新解生成方式）
这是 SA 设计中最关键的部分。好的邻域结构应该：
- 保证解空间任意两点之间可达
- 扰动幅度适中（太大则退化为随机搜索，太小则难以跳出局部最优）

常见策略：
- **离散问题：** 交换、反转、插入操作
- **连续问题：** $x' = x + \epsilon$，其中 $\epsilon \sim N(0, \sigma^2)$，$\sigma$ 随温度降低而减小

#### 3. 退火计划参数

| 参数 | 说明 | 典型值 |
|------|------|--------|
| $T_0$ | 初始温度（足够高使接受率约 0.8~0.9） | 通过试算确定 |
| $T_{\min}$ | 终止温度（很低的温度） | $10^{-3} \sim 10^{-8}$ |
| $\alpha$ | 冷却率（越接近 1 搜索越精细） | 0.90 ~ 0.99 |
| $L$ | 每温度迭代数（Markov 链长） | 100 ~ 1000 |
| $N_{\text{stop}}$ | 连续无改进的冻结轮数 | 视问题定 |

---

## ⚖️ 优缺点

| ✅ 优点 | ❌ 缺点 |
|--------|--------|
| **理论上以概率 1 收敛到全局最优**（对数降温） | **收敛速度慢**，需要大量函数评估 |
| 对目标函数性质要求低（不需可微、连续） | 对参数（$T_0$, $\alpha$, $L$）敏感，需要调参 |
| 实现简单，算法逻辑直观 | 每次只操作一个解，无种群信息交换 |
| 可与其他算法混合（SA + GA, SA + PSO） | 邻域结构设计依赖于问题领域知识 |
| 天然支持并行计算（多链并行SA） | 缺乏记忆机制，可能重复搜索已访问区域 |

## 💻 使用方法 (Python)

### 1. 通用模拟退火框架

```python
import numpy as np
import copy
import math

class SimulatedAnnealing:
    """
    通用模拟退火算法框架
    
    通过继承此类并实现 neighbor() 和 energy() 即可求解具体问题
    """
    
    def __init__(self, initial_temp=100.0, min_temp=1e-5, 
                 cooling_rate=0.95, steps_per_temp=100):
        self.T0 = initial_temp
        self.T_min = min_temp
        self.alpha = cooling_rate
        self.L = steps_per_temp
    
    def energy(self, state):
        """目标函数（需子类实现）"""
        raise NotImplementedError
    
    def neighbor(self, state):
        """生成邻域新解（需子类实现）"""
        raise NotImplementedError
    
    def run(self, initial_state, verbose=False, track_history=False):
        """
        执行模拟退火搜索
        
        参数:
            initial_state: 初始解
            verbose: 是否打印中间过程
            track_history: 是否记录搜索历史
        返回:
            best_state: 最优解
            best_energy: 最优值
            history: (可选) 搜索历史
        """
        current = copy.deepcopy(initial_state)
        current_energy = self.energy(current)
        
        best = copy.deepcopy(current)
        best_energy = current_energy
        
        T = self.T0
        history = [] if track_history else None
        iteration = 0
        
        while T > self.T_min:
            for _ in range(self.L):
                iteration += 1
                
                # 产生新解
                new_state = self.neighbor(current)
                new_energy = self.energy(new_state)
                
                delta = new_energy - current_energy
                
                # Metropolis 准则
                if delta < 0 or np.random.rand() < math.exp(-delta / T):
                    current = new_state
                    current_energy = new_energy
                    
                    if current_energy < best_energy:
                        best = copy.deepcopy(current)
                        best_energy = current_energy
                
                if track_history:
                    history.append((iteration, current_energy, best_energy, T))
            
            # 降温
            T *= self.alpha
            
            if verbose:
                print(f"T={T:.6f}, current={current_energy:.4f}, best={best_energy:.4f}")
        
        return best, best_energy, history
```

### 2. TSP 旅行商问题实例

```python
import numpy as np

class TSP_SA(SimulatedAnnealing):
    """用 SA 求解旅行商问题"""
    
    def __init__(self, cities, initial_temp=1000, min_temp=1e-5,
                 cooling_rate=0.98, steps_per_temp=200):
        super().__init__(initial_temp, min_temp, cooling_rate, steps_per_temp)
        self.cities = cities          # 城市坐标列表 [(x1,y1), ...]
        self.n = len(cities)
        # 预计算距离矩阵
        self.dist = np.zeros((self.n, self.n))
        for i in range(self.n):
            for j in range(self.n):
                self.dist[i][j] = np.linalg.norm(np.array(cities[i]) - np.array(cities[j]))
    
    def energy(self, state):
        """路径总长度"""
        total = 0
        for i in range(self.n - 1):
            total += self.dist[state[i]][state[i+1]]
        total += self.dist[state[-1]][state[0]]  # 回到起点
        return total
    
    def neighbor(self, state):
        """生成新路径：随机交换两个城市的位置"""
        new = copy.deepcopy(state)
        i, j = np.random.choice(self.n, 2, replace=False)
        new[i], new[j] = new[j], new[i]
        return new

# 使用示例
cities = [(0,0), (1,5), (5,2), (6,6), (2,7), (8,3), (3,1), (7,4)]
tsp = TSP_SA(cities, initial_temp=1000, cooling_rate=0.98)

# 随机初始路径
initial = list(range(len(cities)))
np.random.shuffle(initial)

best_route, best_dist, history = tsp.run(initial, verbose=True, track_history=True)
print(f"最短路径长度: {best_dist:.2f}")
print(f"最优路径: {best_route}")
```

### 3. 连续函数优化实例

```python
class ContinuousSA(SimulatedAnnealing):
    """用 SA 优化连续函数"""
    
    def __init__(self, func, bounds, initial_temp=100, min_temp=1e-5,
                 cooling_rate=0.95, steps_per_temp=100):
        super().__init__(initial_temp, min_temp, cooling_rate, steps_per_temp)
        self.func = func          # 目标函数
        self.bounds = bounds      # 边界 [(x1_min, x1_max), ...]
        self.dim = len(bounds)
    
    def energy(self, state):
        return self.func(np.array(state))
    
    def neighbor(self, state):
        """在当前解附近随机扰动"""
        new = copy.deepcopy(state)
        # 随机选一个维度扰动
        dim = np.random.randint(self.dim)
        # 扰动幅度随温度自适应
        scale = (self.bounds[dim][1] - self.bounds[dim][0]) * 0.1
        new[dim] += np.random.randn() * scale
        # 边界处理
        new[dim] = max(self.bounds[dim][0], min(self.bounds[dim][1], new[dim]))
        return new

# 测试函数：Rastrigin 函数（多峰，最小值在 x=0 处）
def rastrigin(x, A=10):
    return A * len(x) + sum(xi**2 - A * np.cos(2*np.pi*xi) for xi in x)

# 使用示例
bounds = [(-5.12, 5.12), (-5.12, 5.12)]  # 二维
sa = ContinuousSA(rastrigin, bounds, initial_temp=100, cooling_rate=0.95)

initial_sol = [np.random.uniform(-5, 5) for _ in range(2)]
best_x, best_y, _ = sa.run(initial_sol, verbose=True)

print(f"最优解 x = {best_x}")
print(f"最优值 f(x) = {best_y:.6f}")
print(f"理论最小值 f(0,0) = {rastrigin([0,0]):.6f}")
```

### 关键参数调优建议

| 参数 | 太小的后果 | 太大的后果 | 建议调法 |
|------|-----------|-----------|---------|
| $T_0$ | 过早收敛到局部最优 | 浪费前期计算时间 | 试调使初始接受率约 0.8 |
| $\alpha$ | 冷却太快，探索不足 | 收敛极慢 | 先试 0.95，根据结果调整 |
| $L$ | 同一温度下搜索不足 | 计算量过大 | 设置为问题规模的 10~100 倍 |

## 📊 实例应用

### 实例 1：数学建模中的 TSP 问题

> **问题：** 给定 31 个城市的坐标，求最短哈密顿回路（TSP 问题）。
> **SA 方案：** 邻域操作为 2-opt 交换（反转路径中一段），冷却率为 0.99，每温度迭代 500 次。
> **结果：** 与最优解的误差通常在 1%~3% 以内，计算时间远小于精确算法。

### 实例 2：选址问题

> **问题：** 在二维平面上选择 $k$ 个设施位置，使所有需求点到最近设施的距离之和最小。
> **SA 方案：** 邻域操作为随机移动一个设施的位置，扰动幅度随温度减小。
> **优势：** 相比 K-Means 类方法，SA 不易陷入局部最优。

## 🔗 关联算法

- [[粒子群算法 (PSO)]] — 基于种群的启发式优化，利用粒子间信息共享
- **遗传算法 (GA)** — 同样是元启发式，但基于种群演化和交叉变异
- **禁忌搜索 (TS)** — 利用记忆机制避免重复搜索，与 SA 互补
- **蚁群算法 (ACO)** — 正反馈机制，适合离散组合优化

## 📝 补充说明

### 理论收敛性

SA 的收敛性依赖于退火计划。Geman & Geman (1984) 证明了：若温度按 $T_k \geq \frac{c}{\ln(k+1)}$ 下降，则 SA 以概率 1 收敛到全局最优。但实际中这种对数降温过于缓慢，工程上通常使用指数降温。

### 与梯度下降的区别

| 方面 | SA | 梯度下降 |
|------|-----|---------|
| 接受差解 | 是（概率性） | 否 |
| 需要梯度 | 否 | 是 |
| 全局搜索 | 强（尤其是高温期） | 弱 |
| 收敛速度 | 慢 | 快 |

### 实际使用技巧

1. **归一化目标函数**：若 $\Delta E$ 数量级过大，$\exp(-\Delta E/T)$ 可能数值溢出，建议将目标函数归一化
2. **重启策略**：从不同初始解运行多次，取最优结果
3. **自适应退火**：根据当前接受率动态调整降温速度
4. **混合算法**：SA 做全局探索 + 局部搜索做精细优化
