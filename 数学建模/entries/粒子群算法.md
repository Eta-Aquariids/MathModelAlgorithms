## 📖 算法原理

**粒子群算法（Particle Swarm Optimization, PSO）** 是一种基于**群体智能**的随机优化算法，由 Kennedy 和 Eberhart 于 1995 年提出。其灵感来源于鸟群觅食和鱼群游动的社会行为。

### 生物类比

设想一群鸟在一片区域内随机寻找食物（全局最优解）：
- 每只鸟都不知道食物在哪，但知道自己当前的位置距离食物有多远
- 每只鸟能记住自己**曾经到达的离食物最近的位置**
- 鸟群之间会**共享信息**，每只鸟知道**群体中任何鸟找到的最远位置**
- 每只鸟在飞行时会综合考虑三个因素：
  1. **惯性**：保持当前飞行方向
  2. **个体认知**：飞向自己曾到过的最佳位置
  3. **社会引导**：飞向群体中任何鸟发现的最佳位置

### 数学模型

#### 1. 基本定义

在一个 $D$ 维搜索空间中，有 $N$ 个粒子（种群大小）。每个粒子 $i$ 在时刻 $t$ 有两个属性：

- **位置：** $\mathbf{x}_i(t) = (x_{i1}, x_{i2}, \ldots, x_{iD})$ — 表示一个候选解
- **速度：** $\mathbf{v}_i(t) = (v_{i1}, v_{i2}, \ldots, v_{iD})$ — 决定移动方向和步长

#### 2. 记忆信息

每个粒子维护两个最优位置：

- **个体最优（pbest）：** $\mathbf{p}_i$ — 粒子 $i$ 历史上找到的最优位置
- **全局最优（gbest）：** $\mathbf{g}$ — 整个种群历史上找到的最优位置

#### 3. 速度更新公式

这是 PSO 的**核心公式**。在第 $t+1$ 次迭代中，粒子 $i$ 的第 $d$ 维速度更新为：

$$
v_{id(t+1) = w \cdot v_{id}(t) + c_1 r_1 [p_{id} - x_{id}(t)] + c_2 r_2 [g_d - x_{id}(t)]}
$$

其中：

| 符号 | 名称 | 含义 | 典型值 |
|------|------|------|--------|
| $w$ | **惯性权重** | 控制上一速度的保留程度 | 0.4 ~ 0.9 |
| $c_1$ | **个体学习因子（认知系数）** | 粒子向自身历史最优趋近的权重 | 1.5 ~ 2.0 |
| $c_2$ | **社会学习因子（社会系数）** | 粒子向全局最优趋近的权重 | 1.5 ~ 2.0 |
| $r_1, r_2$ | 随机数 | 在 $[0, 1]$ 上均匀分布 | 每次更新重新生成 |

**三项的物理意义：**

```
第1项        第2项              第3项
惯性   +   个体认知(飞向自己)   +   社会引导(飞向群体)
 │             │                      │
 ↓             ↓                      ↓
保持探索方向   回忆自我经验           学习他人经验
```

#### 4. 位置更新公式

$$
x_{id(t+1) = x_{id}(t) + v_{id}(t+1)}
$$

#### 5. 标准 PSO 算法流程

```
初始化粒子群（位置和速度随机）
FOR t = 1 TO 最大迭代次数:
    FOR 每个粒子 i:
        计算适应度 f(x_i)
        IF f(x_i) < f(p_i):     # 更新个体最优
            p_i = x_i
        IF f(x_i) < f(g):       # 更新全局最优
            g = x_i
    
    FOR 每个粒子 i:
        FOR 每个维度 d:
            更新速度 v_id(t+1)
            更新位置 x_id(t+1)
            边界处理

RETURN g 及其适应度
```

### 变体与改进

#### 1. 惯性权重策略

惯性权重 $w$ 控制全局探索与局部开发之间的平衡：

| 策略 | 公式 | 效果 |
|------|------|------|
| 固定值 | $w = 0.7$ | 简单但需调参 |
| **线性递减** | $w(t) = w_{\max} - \frac{t}{T}(w_{\max} - w_{\min})$ | 先全局探索，后局部精化，最常用 |
| 自适应 | 根据种群多样性动态调整 | 效果好但实现复杂 |

典型线性递减范围：$w_{\max} = 0.9$ → $w_{\min} = 0.4$

#### 2. 速度钳制

为防止粒子飞出搜索空间，限制最大速度：

$$
v_{id} = \text{sign}(v_{id}) \cdot \min(|v_{id}|, V_{\max})
$$

通常 $V_{\max} = k \cdot (x_{\max} - x_{\min})$，$k \in [0.1, 0.2]$。

#### 3. 边界处理

| 方法 | 做法 | 优缺点 |
|------|------|--------|
| 吸收 | 撞边后速度置零 | 损失多样性 |
| 反射 | 撞边后反向弹回 | 保持多样性，较常用 |
| 不可见 | 超出边界不计算适应度 | 简单但可能浪费计算 |

#### 4. 压缩因子法 (Clerc)

替代惯性权重的一种方法，保证收敛性：

$$
v_{id}(t+1) = \chi \left[ v_{id}(t) + \varphi_1 r_1(p_{id} - x_{id}) + \varphi_2 r_2(g_d - x_{id}) \right]
$$

其中压缩因子 $\chi = \frac{2}{|2 - \varphi - \sqrt{\varphi^2 - 4\varphi}|}$，$\varphi = \varphi_1 + \varphi_2 > 4$。

| 适用问题类型 | 具体例子 |
|-------------|---------|
| **连续函数优化** | 多峰函数求全局最小值、神经网络权值训练 |
| **工程参数优化** | PID 控制器参数整定、天线设计优化 |
| **约束优化问题** | 带约束的生产计划、能源调度 |
| **多目标优化** | MOPSO 求解 Pareto 前沿 |
| **动态优化** | 时变环境下的实时优化（需改进算法） |

**数据要求：**
- **数据类型：** 主要适用于连续变量的实值优化（离散问题需编码或使用二进制 PSO）
- **核心要求：** 目标函数可计算，变量有界
- **前提假设：** 无特殊假设（不要求凸性、可微性、连续性）

## 📋 详细算法步骤

### 步骤 1：初始化

1. 设定参数：种群大小 $N$、最大迭代次数 $T$、$w$, $c_1$, $c_2$, $V_{\max}$
2. 对每个粒子 $i$：
   - 在搜索空间内随机初始化位置 $\mathbf{x}_i$
   - 随机初始化速度 $\mathbf{v}_i$（通常限制在 $[-V_{\max}, V_{\max}]$）
   - 个体最优 $\mathbf{p}_i = \mathbf{x}_i$
3. 计算所有粒子的适应度，设定全局最优 $\mathbf{g}$

### 步骤 2：迭代优化

循环以下步骤直到满足终止条件：

1. **更新惯性权重**（若使用线性递减策略）

2. **对每个粒子 $i$：**
   - 更新速度（按速度公式）
   - 速度钳制（若超限）
   - 更新位置
   - 边界处理

3. **对每个粒子 $i$：**
   - 计算适应度 $f(\mathbf{x}_i)$
   - 若优于个体最优 $\mathbf{p}_i$，则更新 $\mathbf{p}_i$
   - 若优于全局最优 $\mathbf{g}$，则更新 $\mathbf{g}$

### 步骤 3：终止与输出

终止条件可以是：
- 达到最大迭代次数
- **全局最优连续 $K$ 代无改进**（早停）
- 种群多样性低于阈值

输出全局最优解 $\mathbf{g}$ 及最优值 $f(\mathbf{g})$。

### 参数选择指南

| 参数 | 影响 | 建议范围 | 推荐默认值 |
|------|------|---------|-----------|
| $N$ | 种群多样性 vs 计算量 | 20 ~ 60 | 30 |
| $T$ | 搜索充分性 | 100 ~ 2000 | 500 |
| $w$ | 探索 vs 开发平衡 | 0.4 ~ 0.9 | 线性递减 0.9→0.4 |
| $c_1$ | 个体经验权重 | 1.0 ~ 2.5 | 1.5 |
| $c_2$ | 社会经验权重 | 1.0 ~ 2.5 | 1.5 |
| $V_{\max}$ | 搜索步长限制 | $0.1 \sim 0.2 \times \text{搜索范围}$ | 取决于问题 |

## ⚖️ 优缺点

| ✅ 优点 | ❌ 缺点 |
|--------|--------|
| **实现极其简单**（核心代码仅 10 行左右） | **可能早熟收敛**：所有粒子被 gbest 吸引，失去多样性 |
| **参数少**，调整直观 | 对**高维问题**（$D > 30$）性能显著下降 |
| 无需目标函数梯度信息 | **无收敛性理论保证**（不像 SA 有渐近收敛性） |
| **收敛速度快**，尤其在初期 | **离散和组合优化**需要专门编码（二进制 PSO） |
| 天然**并行计算**友好 | 全局最优更新策略较简单，易受异常粒子影响 |
| 记忆机制避免重复搜索 | 标准 PSO 不支持约束处理（需额外方法） |

## 💻 使用方法 (Python)

### 1. 标准 PSO 实现

```python
import numpy as np

class ParticleSwarmOptimizer:
    """
    标准粒子群优化算法
    """
    
    def __init__(self, n_particles=30, n_dims=2, bounds=None,
                 w=0.7, c1=1.5, c2=1.5, max_iter=500, 
                 w_strategy='linear_decrease', v_max_ratio=0.2):
        """
        参数:
            n_particles: 粒子数
            n_dims: 问题维度
            bounds: 边界列表 [(min, max), ...]
            w: 惯性权重
            c1: 个体学习因子
            c2: 社会学习因子
            max_iter: 最大迭代次数
            w_strategy: 'fixed' 或 'linear_decrease'
            v_max_ratio: 最大速度为范围的 v_max_ratio 倍
        """
        self.N = n_particles
        self.D = n_dims
        self.bounds = bounds if bounds else [(-10, 10)] * n_dims
        self.c1 = c1
        self.c2 = c2
        self.max_iter = max_iter
        self.w_strategy = w_strategy
        self.w = w
        self.w_max = 0.9
        self.w_min = 0.4
        
        # 计算速度限制
        self.v_max = []
        for (low, high) in self.bounds:
            self.v_max.append(v_max_ratio * (high - low))
        self.v_max = np.array(self.v_max)
        
        # 初始化粒子群
        self.x = np.zeros((self.N, self.D))  # 位置
        self.v = np.zeros((self.N, self.D))  # 速度
        self.pbest = np.zeros((self.N, self.D))  # 个体最优位置
        self.pbest_val = np.full(self.N, np.inf)  # 个体最优值
        self.gbest = np.zeros(self.D)  # 全局最优位置
        self.gbest_val = np.inf  # 全局最优值
        
        # 记录
        self.convergence_curve = []  # 收敛曲线
    
    def init_population(self):
        """随机初始化粒子位置和速度"""
        for i in range(self.N):
            for d in range(self.D):
                low, high = self.bounds[d]
                self.x[i, d] = np.random.uniform(low, high)
                self.v[i, d] = np.random.uniform(-self.v_max[d], self.v_max[d])
        self.pbest = self.x.copy()
    
    def evaluate(self, x):
        """
        适应度函数（由子类重写或外部传入）
        返回: 标量适应度值（越小越好）
        """
        raise NotImplementedError
    
    def update_inertia(self, t):
        """更新惯性权重"""
        if self.w_strategy == 'linear_decrease':
            # 线性递减：0.9 → 0.4
            self.w = self.w_max - (self.w_max - self.w_min) * (t / self.max_iter)
    
    def optimize(self, verbose=True):
        """
        执行 PSO 优化
        
        返回:
            gbest: 全局最优位置
            gbest_val: 全局最优值
            convergence: 收敛曲线
        """
        self.init_population()
        
        for t in range(self.max_iter):
            # 更新惯性权重
            self.update_inertia(t)
            
            # 评估每个粒子
            for i in range(self.N):
                val = self.evaluate(self.x[i])
                
                # 更新个体最优
                if val < self.pbest_val[i]:
                    self.pbest_val[i] = val
                    self.pbest[i] = self.x[i].copy()
                
                # 更新全局最优
                if val < self.gbest_val:
                    self.gbest_val = val
                    self.gbest = self.x[i].copy()
            
            # 更新速度和位置
            for i in range(self.N):
                r1 = np.random.rand(self.D)
                r2 = np.random.rand(self.D)
                
                # 速度更新（核心公式）
                self.v[i] = (self.w * self.v[i] 
                            + self.c1 * r1 * (self.pbest[i] - self.x[i])
                            + self.c2 * r2 * (self.gbest - self.x[i]))
                
                # 速度钳制
                self.v[i] = np.clip(self.v[i], -self.v_max, self.v_max)
                
                # 位置更新
                self.x[i] = self.x[i] + self.v[i]
                
                # 边界处理（反射）
                for d in range(self.D):
                    low, high = self.bounds[d]
                    if self.x[i, d] < low:
                        self.x[i, d] = low + (low - self.x[i, d])
                        self.v[i, d] = -self.v[i, d]
                    elif self.x[i, d] > high:
                        self.x[i, d] = high - (self.x[i, d] - high)
                        self.v[i, d] = -self.v[i, d]
            
            # 记录收敛曲线
            self.convergence_curve.append(self.gbest_val)
            
            if verbose and (t % 50 == 0 or t == self.max_iter - 1):
                print(f"迭代 {t:4d}/{self.max_iter}, w={self.w:.4f}, 最优值={self.gbest_val:.6e}")
        
        return self.gbest, self.gbest_val, self.convergence_curve


### 2. 使用 PSO 优化函数

# 待优化的目标函数：Sphere 函数（最小值在原点）
class SphereOptimizer(ParticleSwarmOptimizer):
    def evaluate(self, x):
        return np.sum(x ** 2)

# 使用示例
pso = SphereOptimizer(
    n_particles=30, n_dims=3,
    bounds=[(-5.12, 5.12)] * 3,
    w_strategy='linear_decrease',
    c1=1.5, c2=1.5, max_iter=200
)

gbest, gbest_val, curve = pso.optimize(verbose=True)
print(f"\n最优解: {gbest}")
print(f"最优值: {gbest_val:.8f}")
print(f"理论最优: 0.0 (在原点)")


### 3. 带约束的 PSO（罚函数法）

class ConstrainedPSO(ParticleSwarmOptimizer):
    """
    带约束的 PSO：使用外点罚函数法处理约束
    """
    def __init__(self, constraint_funcs, penalty_coef=1000, **kwargs):
        """
        constraint_funcs: 约束函数列表 [g1(x), g2(x), ...] 
                          每个 gi(x) <= 0 表示可行
        """
        super().__init__(**kwargs)
        self.constraints = constraint_funcs
        self.penalty = penalty_coef
    
    def evaluate(self, x):
        # 原始目标
        f = np.sum(x ** 2)  # 以 Sphere 为例
        
        # 约束违反度
        violation = 0
        for g in self.constraints:
            violation += max(0, g(x))  # 违反量
        
        # 罚函数
        return f + self.penalty * violation

def parameter_sweep():
    """
    不同参数对 PSO 性能的影响分析
    """
    results = {}
    
    # 测试不同惯性权重的效果
    w_configs = [
        ('fixed w=0.4', lambda: ParticleSwarmOptimizer(w=0.4, n_dims=5, max_iter=200)),
        ('fixed w=0.9', lambda: ParticleSwarmOptimizer(w=0.9, n_dims=5, max_iter=200)),
        ('linear 0.9→0.4', lambda: ParticleSwarmOptimizer(
            w_strategy='linear_decrease', n_dims=5, max_iter=200)),
    ]
    
    for name, builder in w_configs:
        pso = builder()
        pso.bounds = [(-10, 10)] * 5
        original_eval = pso.evaluate
        pso.evaluate = lambda x: np.sum(x ** 2)
        _, val, _ = pso.optimize(verbose=False)
        results[name] = val
    
    return results
```

## 🔗 关联算法

- [[模拟退火算法 (SA)]] — 单点搜索的启发式算法，与 PSO 的种群搜索形成对比
- **遗传算法 (GA)** — 也是种群算法，但依赖交叉和变异，PSO 没有交叉操作
- **差分进化 (DE)** — 同样基于种群，但用差分变异，在高维问题上比 PSO 更鲁棒
- **蚁群算法 (ACO)** — 群体智能的另一分支，侧重离散组合优化

## 📝 补充说明

### PSO vs SA vs GA 对比

| 方面 | PSO | SA | GA |
|------|-----|-----|-----|
| 搜索方式 | 种群协同 | 单点游走 | 种群进化 |
| 信息共享 | 显式（gbest） | 无 | 隐式（交叉） |
| 收敛速度 | 快 | 慢 | 中 |
| 全局搜索能力 | 易早熟 | 强 | 较强 |
| 实现难度 | 最简单 | 简单 | 中等 |
| 参数数量 | 4~5 个 | 3~4 个 | 多（选择、交叉、变异率） |

### 早熟收敛与多样性保持

PSO 最大的问题是**早熟收敛**：所有粒子被 gbest 吸引，种群多样性迅速丧失。改进方法：

1. **自适应惯性权重**：多样性高时减小 $w$（加强局部搜索），多样性低时增大 $w$（增强探索）
2. **多子群策略**：将种群分成多个子群，各自独立搜索后再融合
3. **扰动策略**：当全局最优长时间无改进时，随机重置部分粒子
4. **结合其他算法**：PSO + SA 混合（对 gbest 施加 SA 扰动）

### 拓扑结构

标准 PSO 使用**全连接拓扑**（每个粒子都向全局最优学习）。其他拓扑选择：

- **环形拓扑：** 粒子只与邻居通信，收敛慢但多样性好
- **冯诺依曼拓扑：** 网格结构，适用中等连接
- **随机拓扑：** 每次迭代随机选择信息源

### 实际使用建议

1. **先试标准 PSO**：线性递减 $w$（0.9→0.4），$c_1 = c_2 = 1.5$，$N = 30$
2. **若结果不理想**：
   - 早熟（结果太差）：增大 $w$、增大 $N$、尝试环形拓扑
   - 收敛太慢：增大 $c_2$、减小 $w$、使用全连接拓扑
3. **多次独立运行**：PSO 是随机算法，建议运行 20~30 次取最优
4. **归一化变量**：将各维变量归一化到 $[0, 1]$ 或 $[-1, 1]$，以便参数设置
