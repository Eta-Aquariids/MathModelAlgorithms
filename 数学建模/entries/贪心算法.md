## 📖 算法原理

**贪心算法** 在每一步决策时都选择当前状态下**最优**的选择（局部最优），期望通过一系列局部最优选择达到全局最优。

### 核心思想

> **"只看眼前，不管未来"**

每一步选当前最好的，不回头调整。

### 适用条件

一个问题能用贪心求解，需要满足：

| 性质 | 含义 |
|------|------|
| **最优子结构** | 全局最优解包含子问题的最优解 |
| **贪心选择性质** | 通过局部最优选择能导出全局最优解（需证明） |

> 并非所有问题都满足贪心选择性质，不满足时贪心只能得到**近似解**。

---

## 🎯 适用场景

| 问题 | 贪心策略 | 最优性 |
|:----:|---------|:-----:|
| **活动选择** | 选结束时间最早的 | ✅ 最优 |
| **哈夫曼编码** | 合并频次最小的两个字符 | ✅ 最优 |
| **最小生成树 (Kruskal)** | 选最短的不形成环的边 | ✅ 最优 |
| **最小生成树 (Prim)** | 选离树最近的顶点 | ✅ 最优 |
| **Dijkstra 最短路径** | 选距离源点最近的未确定节点 | ✅ 最优 |
| **找零问题** | 先用最大面额 | ⚠️ 依赖币制 |
| **背包（分数）** | 选单位价值最高的 | ✅ 最优 |
| **0-1 背包** | 选单位价值最高的 | ❌ 不一定最优 |

## 💻 使用方法 (Python)

```python
# 活动选择问题：选最多的互不重叠的活动
def activity_selection(activities):
    """
    activities: [(开始时间, 结束时间), ...]
    返回: 选中的活动索引
    """
    # 按结束时间排序
    idx = sorted(range(len(activities)), key=lambda i: activities[i][1])
    selected = [idx[0]]
    last_end = activities[idx[0]][1]
    
    for i in idx[1:]:
        if activities[i][0] >= last_end:
            selected.append(i)
            last_end = activities[i][1]
    
    return selected

# 示例
acts = [(1,4), (3,5), (0,6), (5,7), (3,8), (5,9), (6,10), (8,11), (8,12), (2,13)]
sel = activity_selection(acts)
print(f"选中 {len(sel)} 个活动: {sel}")
```

## ⚖️ 优缺点

| ✅ 优点 | ❌ 缺点 |
|--------|--------|
| 实现简单，运行效率高 | 不是所有问题都能得到最优解 |
| 时间复杂度低（通常 $O(n\log n)$） | 需要严格证明贪心选择性质 |
| 适合作为近似算法 | 对约束条件变化敏感 |
