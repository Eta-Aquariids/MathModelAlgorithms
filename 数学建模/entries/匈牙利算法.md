## 📖 算法原理

**匈牙利算法** 求解**指派问题**——将 $n$ 项任务分配给 $n$ 个人，每人做一项，使总成本最小（或总效益最大）。

### 数学模型

决策变量 $x_{ij} = 1$ 表示第 $i$ 个人做第 $j$ 项任务：

$$
\min \sum_{i=1}^{n}\sum_{j=1}^{n} c_{ij}x_{ij}
$$

约束：每行每列恰好一个 1（每人一任务，每任务一人）。

### 算法核心：König 定理

> 二分图的最大匹配数 = 最小顶点覆盖数

### 算法步骤

1. **行规约：** 每行减去该行最小值
2. **列规约：** 每列减去该列最小值
3. **试指派：** 用最少的线覆盖所有 0 元素
4. **若线数 = n** → 已找到最优指派（从 0 位置读出方案）
5. **若线数 < n** → 在未被覆盖的区域中找到最小值，未覆盖行减去它，覆盖列加上它，回到步骤 3

### KM 算法（求最大权匹配）

当需要求**最大权完美匹配**（而非最小成本）时，用 KM（Kuhn-Munkres）算法。

## 💻 使用方法 (Python)

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

# 成本矩阵：行=人员，列=任务
cost = np.array([
    [9, 6, 5, 7],
    [4, 8, 3, 6],
    [5, 7, 4, 5],
    [7, 6, 8, 4]
])

# 调用匈牙利算法（scipy 内置）
row_ind, col_ind = linear_sum_assignment(cost)

print("人员→任务 指派方案：")
total = 0
for r, c in zip(row_ind, col_ind):
    print(f"  人员 {r+1} → 任务 {c+1}，成本 {cost[r,c]}")
    total += cost[r,c]
print(f"总成本: {total}")
```

### 手动实现核心逻辑

```python
def hungarian(cost):
    """手动实现匈牙利算法（最小化版本）"""
    n = len(cost)
    u = np.zeros(n)  # 行标记
    v = np.zeros(n)  # 列标记
    p = np.zeros(n, dtype=int)  # 匹配
    way = np.zeros(n, dtype=int)
    
    for i in range(1, n + 1):
        p[0] = i
        j0 = 0
        minv = np.full(n, float('inf'))
        used = np.zeros(n, dtype=bool)
        while True:
            used[j0] = True
            i0 = p[j0]
            delta = float('inf')
            j1 = 0
            for j in range(1, n + 1):
                if not used[j]:
                    cur = cost[i0-1][j-1] - u[i0-1] - v[j-1]
                    if cur < minv[j]:
                        minv[j] = cur
                        way[j] = j0
                    if minv[j] < delta:
                        delta = minv[j]
                        j1 = j
            for j in range(n):
                if used[j]:
                    u[p[j]-1] += delta
                    v[j] -= delta
                else:
                    minv[j] -= delta
            j0 = j1
            if p[j0] == 0:
                break
        while True:
            j1 = way[j0]
            p[j0] = p[j1]
            j0 = j1
            if j0 == 0:
                break
    # p[j] = i 表示第 j 个任务分配给第 i 个人
    assignment = [-1] * (n + 1)
    for j in range(1, n + 1):
        if p[j] != 0:
            assignment[p[j]] = j
    return assignment[1:], -v[0]
```
