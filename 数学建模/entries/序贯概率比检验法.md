## 📖 算法原理

**序贯概率比检验法（Sequential Probability Ratio Test, SPRT）** 由著名统计学家 Abraham Wald 于 1945 年提出，是序贯分析领域的里程碑式成果。与传统的固定样本量检验不同，SPRT **不预先确定样本量**，而是每次抽取一个样品后立即进行判定，直到有足够证据做出接收或拒收的决策为止。

### 核心思想

SPRT 的核心思想可以用一句话概括：**"边抽边判，够证据就停"**。

每次抽样后，计算当前所有样本的"似然比"（likelihood ratio），即数据在 $H_1$（质量不合格）下的概率与在 $H_0$（质量合格）下的概率之比。将这个比值与两个阈值比较：

- 比值很大 → 数据支持 $H_1$，拒收该批
- 比值很小 → 数据支持 $H_0$，接收该批
- 比值居中 → 证据不足，继续抽样

### 数学模型

#### 1. 假设设定

设批不合格品率为 $p$，检验假设：

$$
H_0: p = p_0 \quad (\text{质量合格}) \quad \longleftrightarrow \quad H_1: p = p_1 \quad (\text{质量不合格})
$$

其中 $p_1 > p_0$，$p_0$ 为合格质量水平（AQL），$p_1$ 为极限质量水平（LQL）。

#### 2. 似然比

令 $X_i$ 为第 $i$ 个样品的检测结果（$X_i=1$ 表示不合格，$X_i=0$ 表示合格）。前 $m$ 个样本的似然比为：

$$
\lambda_m = \frac{L(p_1 | X_1, X_2, \ldots, X_m)}{L(p_0 | X_1, X_2, \ldots, X_m)}
= \frac{\displaystyle\prod_{i=1}^{m} p_1^{X_i} (1-p_1)^{1-X_i}}{\displaystyle\prod_{i=1}^{m} p_0^{X_i} (1-p_0)^{1-X_i}}
= \frac{p_1^{d_m}(1-p_1)^{m-d_m}}{p_0^{d_m}(1-p_0)^{m-d_m}}
$$

其中 $d_m = \sum_{i=1}^{m} X_i$ 为前 $m$ 次检测中的不合格品总数。

#### 3. 判定阈值

根据生产方风险 $\alpha$ 和使用方风险 $\beta$ 设定：

$$
\boxed{A = \frac{1-\beta}{\alpha}, \quad B = \frac{\beta}{1-\alpha}}
$$

阈值 $A$ 和 $B$ 的推导基于对两类错误概率的控制要求：
- 当 $p = p_0$ 时，错误拒收的概率 $\leq \alpha$
- 当 $p = p_1$ 时，错误接收的概率 $\leq \beta$

#### 4. 判定规则

$$
\boxed{
\begin{cases}
\lambda_m \geq A & \Rightarrow \text{拒绝 } H_0 \text{，拒收该批} \\
\lambda_m \leq B & \Rightarrow \text{接受 } H_0 \text{，接收该批} \\
B < \lambda_m < A & \Rightarrow \text{继续抽样}
\end{cases}
}
$$

#### 5. 对数形式（更便于计算）

为避免数值溢出和简化计算，通常取自然对数：

$$
\ln \lambda_m = d_m \ln\frac{p_1}{p_0} + (m - d_m) \ln\frac{1-p_1}{1-p_0}
$$

判定规则变为：

$$
\boxed{
\begin{cases}
\ln \lambda_m \geq \ln A & \Rightarrow \text{拒收} \\
\ln \lambda_m \leq \ln B & \Rightarrow \text{接收} \\
\ln B < \ln \lambda_m < \ln A & \Rightarrow \text{继续}
\end{cases}
}
$$

#### 6. 决策边界图示

以样本量 $m$ 为横轴、不合格品数 $d$ 为纵轴，可得两条平行的决策边界线：

$$
\begin{aligned}
\text{拒收线（上线）: } & d = s \cdot m + h_1 \\
\text{接收线（下线）: } & d = s \cdot m - h_0
\end{aligned}
$$

其中：

$$
\begin{aligned}
s &= \frac{\ln\frac{1-p_0}{1-p_1}}{\ln\frac{p_1}{p_0} - \ln\frac{1-p_1}{1-p_0}} \quad (\text{斜率}) \\
h_0 &= \frac{\ln\frac{1-\alpha}{\beta}}{-\ln\frac{p_1}{p_0} + \ln\frac{1-p_1}{1-p_0}} \quad (\text{接收截距}) \\
h_1 &= \frac{\ln\frac{1-\beta}{\alpha}}{\ln\frac{p_1}{p_0} - \ln\frac{1-p_1}{1-p_0}} \quad (\text{拒收截距})
\end{aligned}
$$

每次抽样后，将点 $(m, d)$ 标在图上，落在哪个区域就执行相应的决策。

#### 7. 平均样本量（ASN）

SPRT 的一个重要优势是平均样本量（Average Sample Number, ASN）最小。当真实不合格品率为 $p$ 时，ASN 的理论值为：

$$
E_p(m) \approx 
\begin{cases}
\dfrac{\ln B}{s_p \ln\frac{p_1}{p_0} + (1-s_p)\ln\frac{1-p_1}{1-p_0}}, & p \neq s \\
\dfrac{\ln A \cdot \ln B}{[\ln\frac{p_1}{p_0} \cdot \ln\frac{1-p_1}{1-p_0}]}, & p = s
\end{cases}
$$

其中 $s_p = \ln\frac{1-p}{1-p_0} / [\ln\frac{p}{p_0} - \ln\frac{1-p}{1-p_0}]$。

ASN 曲线在 $p$ 接近 $p_0$ 或 $p_1$ 时最小，在 $p$ 介于两者之间时较大。

## 🎯 适用场景

| 适用问题类型 | 具体例子 |
|-------------|---------|
| **破坏性检验** | 弹药引信可靠性测试、食品保质期测试 |
| **检验成本极高的场景** | 高端芯片功能测试、航天零件检测 |
| **需快速决策的流水线监控** | 汽车零部件生产线实时质量报警 |
| **医疗诊断** | 连续检测确诊疾病，尽早终止不必要检查 |
| **临床试验** | 药物有效性试验中，有效/无效时尽早停止 |

**数据要求：**
- **数据类型：** 逐个获得的二值结果（合格/不合格），或可转化为二值的连续数据
- **数据量要求：** 无预设定量，理论上可无限持续（但实际需设截尾）
- **前提假设：**
  - 各样本独立同分布（i.i.d.）
  - 产品质量均匀，无趋势变化
  - $p_0$ 和 $p_1$ 需合理设定，差距过大会降低效率

## 📋 详细算法步骤

### 步骤 1：设定检验参数

确定四个关键参数：
- $p_0$：合格质量水平（如 0.01）
- $p_1$：极限质量水平（如 0.05）
- $\alpha$：生产方风险（通常 0.05）
- $\beta$：使用方风险（通常 0.10）

### 步骤 2：计算决策阈值

$$
\ln A = \ln\frac{1-\beta}{\alpha}, \quad \ln B = \ln\frac{\beta}{1-\alpha}
$$

### 步骤 3：逐次抽样检验

初始化：$m = 0$，$d = 0$。

循环执行以下操作：

1. 从批中抽取 1 个样品进行检测
2. $m = m + 1$
3. 若样品不合格，$d = d + 1$
4. 计算对数似然比：
   $$
   \ln \lambda_m = d \ln\frac{p_1}{p_0} + (m - d) \ln\frac{1-p_1}{1-p_0}
   $$
5. 判定：
   - $\ln \lambda_m \geq \ln A$ → **拒收**，终止
   - $\ln \lambda_m \leq \ln B$ → **接收**，终止
   - 否则回到步骤 1

### 步骤 4：截尾处理（可选，但建议）

为了避免无限抽样，设定最大样本量 $M$（如 $M = 3n_{NC}$，其中 $n_{NC}$ 为对应 NC 方案的样本量）。

若 $m = M$ 仍未决定，则按以下规则强制判定：
- 当 $d/M$ 明显偏向 $p_0$ 则接收
- 当 $d/M$ 明显偏向 $p_1$ 则拒收
- 或使用截尾边界公式判定

> **注意：** 截尾会略微改变真实的生产方和使用方风险，计算时应考虑修正。

### 步骤 5：评估方案（理论计算后可做）

计算 ASN 曲线和 OC 函数，评估方案的抽样效率。

SPRT 的 OC 函数（即当真实 $p$ 时接收的概率）近似为：

$$
P_a(p) \approx \frac{A^{h(p)} - 1}{A^{h(p)} - B^{h(p)}}
$$

其中 $h(p)$ 满足 $\left(\frac{p_1}{p_0}\right)^h \left(\frac{1-p_1}{1-p_0}\right)^{1-h} = 1$。

---

## ⚖️ 优缺点

| ✅ 优点 | ❌ 缺点 |
|--------|--------|
| **平均样本量(ASN)理论上最小**，比固定抽样方案节省 30%~50% 的样本 | **最大样本量无上限**，极端情况下可能需要大量抽样才出结果 |
| 适用于破坏性检验和高成本检测 | 需要逐个检验，不能批量并行操作，管理复杂度高 |
| 同时控制 $\alpha$ 和 $\beta$ 两类风险 | 若设截尾会略微改变风险特性 |
| 质量极好或极差时能极快做出判定 | 对质量"不上不下"的情况反而需要更多样本 |
| Wald-Wolfowitz 定理保证其最优性 | 理论推导较复杂，不易向非统计人员解释 |

## 💻 使用方法 (Python)

### 1. 基础 SPRT 实现

```python
import numpy as np

def sprt(p0, p1, alpha=0.05, beta=0.10, results=None, max_samples=1000):
    """
    序贯概率比检验 (SPRT)
    
    参数:
        p0: 合格质量水平 (H0)
        p1: 不合格质量水平 (H1)
        alpha: 生产方风险 (第I类错误)
        beta: 使用方风险 (第II类错误)
        results: 检测结果生成器/迭代器, None时自动模拟
        max_samples: 截尾样本量上限
        
    返回:
        dict: 包含决策、样本量、不合格数、决策路径等
    """
    # 阈值
    lnA = np.log((1 - beta) / alpha)
    lnB = np.log(beta / (1 - alpha))
    
    # 对数似然比系数
    a = np.log(p1 / p0)
    b = np.log((1 - p1) / (1 - p0))
    
    m = 0      # 累计样本量
    d = 0      # 累计不合格数
    ln_lambda = 0  # 对数似然比
    path = []  # 决策路径 (m, d, ln_lambda)
    
    for m in range(1, max_samples + 1):
        # 获取检测结果
        if results is not None:
            defect = next(results)
        else:
            # 默认以 p0 概率产生不合格（模拟合格批）
            defect = np.random.rand() < p0
        
        if defect:
            d += 1
        
        # 计算对数似然比
        ln_lambda = d * a + (m - d) * b
        path.append((m, d, ln_lambda))
        
        # 判定
        if ln_lambda >= lnA:
            return {
                'decision': 'reject',  # 拒收
                'm': m,
                'd': d,
                'ln_lambda': ln_lambda,
                'lnA': lnA,
                'lnB': lnB,
                'path': path
            }
        elif ln_lambda <= lnB:
            return {
                'decision': 'accept',  # 接收
                'm': m,
                'd': d,
                'ln_lambda': ln_lambda,
                'lnA': lnA,
                'lnB': lnB,
                'path': path
            }
    
    # 截尾处理
    return {
        'decision': 'truncated',
        'm': max_samples,
        'd': d,
        'ln_lambda': ln_lambda,
        'lnA': lnA,
        'lnB': lnB,
        'path': path
    }

# 示例使用
p0, p1 = 0.01, 0.05
result = sprt(p0, p1, alpha=0.05, beta=0.10)
print(f"决策: {result['decision']}")
print(f"样本量: {result['m']}")
print(f"不合格数: {result['d']}")
```

### 2. ASN 曲线计算

```python
def asn_curve(p0, p1, alpha=0.05, beta=0.10, p_values=None):
    """
    计算 SPRT 在给定真实 p 下的平均样本量 (ASN)
    """
    if p_values is None:
        p_values = np.linspace(0.001, 0.10, 50)
    
    lnA = np.log((1 - beta) / alpha)
    lnB = np.log(beta / (1 - alpha))
    a = np.log(p1 / p0)
    b = np.log((1 - p1) / (1 - p0))
    
    asn_list = []
    for p in p_values:
        # 近似公式
        if p == 0 or p == 1:
            asn_list.append(0)
            continue
        
        numerator = lnB * (1 - beta) + lnA * beta
        denominator = p * a + (1-p) * b
        
        if abs(denominator) < 1e-10:
            asn_list.append(np.nan)
        else:
            asn_list.append(abs(numerator / denominator))
    
    return np.array(asn_list)

# 与 NC 抽样法对比
p_vals = np.linspace(0.001, 0.10, 50)
asn_sprt = asn_curve(0.01, 0.05, p_values=p_vals)
n_nc = 200  # 对应 NC 方案的样本量

print(f"SPRT 平均样本量范围: {np.nanmin(asn_sprt):.0f} ~ {np.nanmax(asn_sprt):.0f}")
print(f"NC 固定样本量: {n_nc}")
print(f"SPRT 最大节省: {(1 - np.nanmin(asn_sprt)/n_nc)*100:.0f}%")
```

### 3. 蒙特卡洛模拟评估方案

```python
def simulate_sprt(p_true, p0, p1, alpha=0.05, beta=0.10, n_sim=10000, max_samples=500):
    """
    蒙特卡洛模拟评估 SPRT 在给定真实质量下的表现
    """
    accept_count = 0
    reject_count = 0
    sample_sizes = []
    
    for _ in range(n_sim):
        # 生成检测结果流
        def gen():
            while True:
                yield np.random.rand() < p_true
        
        result = sprt(p0, p1, alpha, beta, results=gen(), max_samples=max_samples)
        sample_sizes.append(result['m'])
        if result['decision'] == 'accept':
            accept_count += 1
        elif result['decision'] == 'reject':
            reject_count += 1
    
    return {
        'p_true': p_true,
        'accept_rate': accept_count / n_sim,
        'reject_rate': reject_count / n_sim,
        'avg_sample_size': np.mean(sample_sizes),
        'std_sample_size': np.std(sample_sizes),
        'max_sample_size': np.max(sample_sizes)
    }

# 示例
sim_result = simulate_sprt(p_true=0.01, p0=0.01, p1=0.05)
print(f"真实质量 p={sim_result['p_true']}")
print(f"接收概率: {sim_result['accept_rate']:.3f}")
print(f"平均样本量: {sim_result['avg_sample_size']:.1f}")
```

## 📊 实例应用

### 实例 1：破坏性检验场景

某军工产品需要检测引信可靠性，检验为破坏性（测一个毁一个）。产品价值极高。

设定参数：$p_0=0.01$（合格），$p_1=0.05$（不合格），$\alpha=0.05$，$\beta=0.10$。

**对比分析：**

| 指标 | NC 抽样法 | SPRT |
|------|----------|------|
| 固定/最大样本量 | $n=200$ | 理论上无上限 |
| **平均样本量（$p=0.01$）** | 200 | **~60**（节省 70%） |
| **平均样本量（$p=0.05$）** | 200 | **~80**（节省 60%） |
| 平均样本量（$p=0.025$） | 200 | ~120（节省 40%） |

SPRT 在该场景下平均可节省 **40%~70%** 的样本量，大幅减少破坏性检验的损失。

### 实例 2：与 NC 抽样法的决策效率对比

对于同一批产品，若质量极好（$p$ 远小于 $p_0$），SPRT 可能在抽检 10~20 个样品后就判定接收；而 NC 抽样法无论如何都要抽够 200 个才能下结论。

## 📝 补充说明

### 历史背景
SPRT 由 Abraham Wald 在二战期间为美军研究军需品检验问题时发明。由于军需品的检验往往是破坏性的，减少样本量具有重大军事和经济意义。Wald 的理论成果后来发表在 1947 年的经典著作《Sequential Analysis》中。

### Wald-Wolfowitz 定理
该定理指出：在给定的 $\alpha$ 和 $\beta$ 下，SPRT 是所有序贯检验方法中平均样本量（ASN）最小的。这奠定了 SPRT 在统计检验中的最优地位。

### 实际应用注意事项

1. **截尾的必要性**：对于质量恰好处于 $p_0$ 和 $p_1$ 之间的产品，SPRT 可能需要较长时间才能做出判定，因此实际应用中几乎都会设置截尾样本量。
2. **实施复杂性**：SPRT 要求逐个检测并实时计算，不适合需要批量检测的场景。
3. **风险修正**：截尾后 $\alpha$ 和 $\beta$ 会略有变化，精确风险可通过蒙特卡洛模拟确定。
4. **趋势检测**：若生产线质量有趋势性变化（如刀具磨损），SPRT 的独立同分布假设可能被违反，需谨慎使用。
