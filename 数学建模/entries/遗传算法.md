## 📖 算法原理

**遗传算法（Genetic Algorithm, GA）** 是一种模拟**生物进化**过程的随机搜索算法，由 John Holland 及其学生于 1975 年提出。其核心思想源自达尔文的**自然选择**和**遗传变异**理论。

### 生物类比

| 生物学概念 | GA 中的对应 | 含义 |
|-----------|------------|------|
| 种群 (Population) | 一组候选解 | 多个解同时搜索 |
| 个体 (Individual) | 一个候选解 | 染色体编码代表解 |
| 染色体 (Chromosome) | 解的编码 | 通常为二进制串或实数向量 |
| 基因 (Gene) | 编码中的一个分量 | 解的某一位 |
| 适应度 (Fitness) | 目标函数值 | 解的优劣程度 |
| 选择 (Selection) | 优胜劣汰 | 好解有更高概率被保留 |
| 交叉 (Crossover) | 基因重组 | 两个父代交换部分基因产生子代 |
| 变异 (Mutation) | 基因突变 | 随机改变基因位，维持多样性 |

### 算法思想

GA 从一个初始种群出发，通过"**选择→交叉→变异**"的迭代过程，使种群不断进化，最终收敛到最优解附近。

$$
\text{初始种群} \xrightarrow{\text{适应度评估}} \xrightarrow{\text{选择}} \xrightarrow{\text{交叉}} \xrightarrow{\text{变异}} \xrightarrow{\text{新一代种群}} \xrightarrow{\text{重复}}
$$

### 核心操作

#### 1. 编码方式

| 编码方式 | 适用问题 | 例子 |
|---------|---------|------|
| **二进制编码** | 组合优化、背包 | 101001... |
| **实数编码** | 连续函数优化 | $[x_1, x_2, \ldots, x_n]$ |
| **排列编码** | 排序问题（TSP） | $[3,1,4,2]$ 表示访问顺序 |
| **树形编码** | 程序/表达式演化 | 语法树 |

#### 2. 选择算子

决定哪些个体进入下一代。适应度越高的个体被选中的概率越大。

**轮盘赌选择（比例选择）：**

$$
P(\text{个体 } i \text{ 被选}) = \frac{f_i}{\sum_{j=1}^{N} f_j}
$$

其中 $f_i$ 为个体 $i$ 的适应度，$N$ 为种群大小。

**锦标赛选择：**
- 随机取出 $k$ 个个体（通常 $k=2$ 或 $3$）
- 选择其中适应度最高的进入下一代
- 重复直到填满下一代

**精英保留策略：**
- 将当前最优的几个个体**直接复制**到下一代（不经过交叉变异）
- 保证最优解不丢失

#### 3. 交叉算子

两个父代交换基因片段产生子代，是 GA 的**主要搜索算子**。

**单点交叉（二进制编码）：**

```
父代A: 101|00101    子代A: 101|11010
父代B: 010|11010 →  子代B: 010|00101
         ↑ 交叉点
```

**两点交叉：**

```
父代A: 10|1001|01    子代A: 10|0110|01
父代B: 01|0110|10 →  子代B: 01|1001|10
```

**模拟二进制交叉 (SBX, 实数编码)：**
适用于实数编码，子代在父代附近产生，保持种群多样性。

**部分映射交叉 (PMX, 排列编码)：**
适用于 TSP 等排列问题，保证子代仍是合法排列。

#### 4. 变异算子

随机改变个体的某些基因位，维持种群多样性，防止早熟收敛。

**二进制变异：** 随机翻转某一位（$0 \leftrightarrow 1$）
**实数变异：** 在当前位置加一个随机扰动
**交换变异（排列）：** 随机交换两个位置的值

**变异概率 $p_m$ 通常很小（0.001 ~ 0.1）。**

## 🎯 适用场景

| 问题类型 | 具体例子 |
|---------|---------|
| **组合优化** | TSP、背包问题、图着色、调度问题 |
| **连续优化** | 多峰函数全局优化（与其他算法混合） |
| **机器学习** | 特征选择、神经网络结构搜索 |
| **工程设计** | 结构优化、电路设计、路径规划 |
| **自动编程** | 遗传编程 (Genetic Programming) |

**数据要求：**
- 只需能计算适应度，无其他数学要求
- 需要合理设计编码和遗传算子

## 📋 详细算法步骤

```
1. 设定参数：种群大小 N, 交叉率 pc, 变异率 pm, 最大代数 T
2. 初始化：随机生成 N 个个体组成初始种群
3. 评估：计算每个个体的适应度
4. FOR gen = 1 TO T:
     a. 选择：用选择算子选出 N 个父代个体
     b. 交叉：按概率 pc 对父代进行交叉，生成子代
     c. 变异：按概率 pm 对子代进行变异
     d. 评估：计算子代适应度
     e. 替换：用子代替换父代（或精英保留策略）
     f. 记录当前最优
5. 返回历史最优解
```

### 参数设置指南

| 参数 | 影响 | 典型范围 |
|------|------|---------|
| 种群大小 $N$ | 大→多样性好但计算慢 | 20 ~ 200 |
| 交叉率 $p_c$ | 大→探索强但可能破坏好解 | 0.6 ~ 0.95 |
| 变异率 $p_m$ | 大→多样性好但收敛慢 | 0.001 ~ 0.1 |
| 精英数 $n_{elite}$ | 大→收敛快但易早熟 | 1 ~ 5 |

---

## ⚖️ 优缺点

| ✅ 优点 | ❌ 缺点 |
|--------|--------|
| **表达能力强**——可解决任意编码形式的问题 | **收敛速度慢**，需要大量适应度评估 |
| 群体搜索天然具有**隐式并行性** | 对编码方案和算子设计敏感 |
| 不依赖梯度，适用于黑箱优化 | 没有收敛性理论保证 |
| 与问题领域无关（只需适应度函数） | 参数（$N, p_c, p_m$）调优较繁琐 |
| 可输出多个满意解供决策 | 对高维连续优化不如 PSO/DE 高效 |

## 💻 使用方法 (Python)

### 1. 通用 GA 框架

```python
import numpy as np
import random

class GeneticAlgorithm:
    """
    通用遗传算法框架
    """
    def __init__(self, pop_size=50, n_genes=10, 
                 crossover_rate=0.8, mutation_rate=0.05,
                 n_elite=2, max_gen=200, gene_bound=(0, 1)):
        self.N = pop_size
        self.n_genes = n_genes
        self.pc = crossover_rate
        self.pm = mutation_rate
        self.n_elite = n_elite
        self.max_gen = max_gen
        self.gene_low, self.gene_high = gene_bound
    
    def fitness(self, individual):
        """适应度函数（需子类重写，越高越好）"""
        raise NotImplementedError
    
    def init_population(self):
        """随机初始化种群"""
        pop = np.random.uniform(
            self.gene_low, self.gene_high, 
            (self.N, self.n_genes)
        )
        return pop.tolist()
    
    def select(self, population, fitness_vals):
        """锦标赛选择"""
        selected = []
        for _ in range(self.N):
            i, j = random.sample(range(len(population)), 2)
            winner = population[i] if fitness_vals[i] > fitness_vals[j] else population[j]
            selected.append(winner[:])
        return selected
    
    def crossover(self, parent1, parent2):
        """模拟二进制交叉 (SBX)"""
        if random.random() > self.pc:
            return parent1[:], parent2[:]
        eta = 15  # 分布指数
        child1, child2 = parent1[:], parent2[:]
        for i in range(self.n_genes):
            if random.random() < 0.5:
                u = random.random()
                beta = (2*u)**(1/(eta+1)) if u <= 0.5 else (1/(2*(1-u)))**(1/(eta+1))
                child1[i] = 0.5 * ((1+beta)*parent1[i] + (1-beta)*parent2[i])
                child2[i] = 0.5 * ((1-beta)*parent1[i] + (1+beta)*parent2[i])
        return child1, child2
    
    def mutate(self, individual):
        """高斯变异"""
        for i in range(self.n_genes):
            if random.random() < self.pm:
                sigma = (self.gene_high - self.gene_low) * 0.1
                individual[i] += random.gauss(0, sigma)
                individual[i] = max(self.gene_low, min(self.gene_high, individual[i]))
        return individual
    
    def run(self, verbose=True):
        """
        执行遗传算法
        
        返回:
            best: 最优个体
            best_fit: 最优适应度
            history: 收敛曲线
        """
        pop = self.init_population()
        history = []
        best = None
        best_fit = -np.inf
        
        for gen in range(self.max_gen):
            # 评估
            fitness_vals = [self.fitness(ind) for ind in pop]
            
            # 记录最优
            gen_best = max(fitness_vals)
            gen_best_idx = fitness_vals.index(gen_best)
            if gen_best > best_fit:
                best_fit = gen_best
                best = pop[gen_best_idx][:]
            history.append(best_fit)
            
            if verbose and (gen % 20 == 0 or gen == self.max_gen - 1):
                print(f"代 {gen:4d}: 最优适应度 = {best_fit:.6f}")
            
            # 精英保留
            elite_indices = np.argsort(fitness_vals)[-self.n_elite:]
            elites = [pop[i][:] for i in elite_indices]
            
            # 选择
            selected = self.select(pop, fitness_vals)
            
            # 交叉
            new_pop = []
            for i in range(0, self.N - self.n_elite, 2):
                p1, p2 = selected[i], selected[i+1]
                c1, c2 = self.crossover(p1, p2)
                new_pop.append(self.mutate(c1))
                new_pop.append(self.mutate(c2))
            
            # 精英加入
            new_pop.extend(elites)
            pop = new_pop[:self.N]
        
        return best, best_fit, history


### 2. 实例：函数最大化

class FunctionMaxGA(GeneticAlgorithm):
    """最大化 f(x) = x1^2 + x2^2, x ∈ [-5,5]"""
    def fitness(self, ind):
        return ind[0]**2 + ind[1]**2

# 使用示例
ga = FunctionMaxGA(pop_size=50, n_genes=2, gene_bound=(-5, 5),
                   crossover_rate=0.8, mutation_rate=0.05,
                   max_gen=100)
best_x, best_f, history = ga.run(verbose=True)
print(f"\n最优解: x1={best_x[0]:.4f}, x2={best_x[1]:.4f}")
print(f"最优值: f(x) = {best_f:.4f}")
```

## 📊 实例应用

### 实例：GA vs SA vs PSO

| 维度 | GA | SA | PSO |
|------|-----|-----|-----|
| 搜索方式 | 种群（交叉+变异） | 单点游走 | 种群（速度更新） |
| 信息共享 | 交叉时隐式共享 | 无 | 显式（gbest 引导） |
| 收敛速度 | 慢 | 慢 | 快 |
| 离散优化 | 天然适合（排列编码） | 需设计邻域 | 需编码转换 |
| 调参复杂度 | 高（3~5个参数） | 中（2~3个参数） | 低（2~3个参数） |

## 🔗 关联算法

- [[模拟退火算法 (SA)]] — 单点搜索，可嵌入 GA 作为局部搜索算子
- [[粒子群算法 (PSO)]] — 同样是种群算法，但信息共享机制不同
- [[蚁群算法 (ACO)]] — 另一种群体智能算法，侧重组合优化
- **差分进化 (DE)** — GA 的变体，用差分变异取代交叉，高维连续优化强于 GA

## 📝 补充说明

- **GA 的核心优势**在于离散/组合优化（TSP、调度、布局等），用排列编码天然适配
- **GA 的弱点**在于连续优化，PSO 和 DE 通常更高效
- GA 是**进化算法 (Evolutionary Algorithm)** 家族中最著名的成员，其他成员包括：进化策略 (ES)、进化规划 (EP)、遗传编程 (GP)
- 数学建模常用 GA 来求解大规模 TSP、背包问题（与 DP 互补）和调度问题
