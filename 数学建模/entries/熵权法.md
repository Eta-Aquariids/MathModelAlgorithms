## 📖 算法原理

**熵权法** 是一种**客观赋权**方法，基于**信息熵**原理：指标的变异程度越大（信息量越大），熵越小，权重越大。

**核心思想：** 某个指标在所有方案上的取值差异越大，说明该指标对区分方案贡献越大，应赋予更大权重。

### 算法步骤

#### 1. 标准化（消除量纲）

$$
p_{ij} = \frac{x_{ij}}{\sum_{i=1}^{m} x_{ij}}
$$

#### 2. 计算信息熵

$$
e_j = -k \sum_{i=1}^{m} p_{ij} \ln(p_{ij}), \quad k = \frac{1}{\ln m}
$$

其中 $m$ 为方案数，$e_j \in [0, 1]$。

#### 3. 计算差异系数

$$
d_j = 1 - e_j
$$

$d_j$ 越大，说明该指标的信息量越大。

#### 4. 确定权重

$$
w_j = \frac{d_j}{\sum_{j=1}^{n} d_j}
$$

## 🎯 适用场景

| 问题类型 | 具体例子 |
|---------|---------|
| 客观确定指标权重 | 与 TOPSIS、模糊评价等方法配合 |
| 数据本身有丰富信息时 | 多指标多方案的评价矩阵已有 |
| 避免主观偏见 | 不希望人为主观赋权时 |

> **注意：** 熵权法只考虑数据的离散程度，不考虑指标本身的实际重要性，因此常与 AHP 组合使用（主客观综合赋权）。

## 💻 使用方法 (Python)

```python
import numpy as np

def entropy_weight(data):
    """熵权法确定客观权重"""
    # 归一化
    p = data / data.sum(axis=0)
    m = len(data)
    k = 1 / np.log(m)
    # 熵值
    e = -k * np.sum(p * np.log(p + 1e-10), axis=0)
    # 差异系数
    d = 1 - e
    # 权重
    w = d / d.sum()
    return w

# 示例：4个方案×3个指标
data = np.array([
    [90, 80, 70],
    [85, 95, 60],
    [78, 75, 92],
    [88, 82, 78]
])
w = entropy_weight(data)
print(f"各指标权重: {w.round(4)}")
```
