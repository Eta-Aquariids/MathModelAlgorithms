## 📖 算法原理

**灰色预测 GM(1,1) 模型** 是灰色系统理论的核心，适用于**小样本、贫信息**的短期预测。用"累加生成"将杂乱原始数据转化为有指数规律的序列，再建立微分方程模型。

### 算法步骤

#### 1. 累加生成 (1-AGO)

原始序列 $X^{(0)} = (x^{(0)}(1), x^{(0)}(2), \ldots, x^{(0)}(n))$ 一次累加得：

$$
x^{(1)}(k) = \sum_{i=1}^{k} x^{(0)}(i)
$$

#### 2. 建立灰微分方程

$$x^{(0)}(k) + a z^{(1)}(k) = b$$

其中 $z^{(1)}(k) = 0.5x^{(1)}(k) + 0.5x^{(1)}(k-1)$ 为邻均值生成序列。

对应的白化微分方程：

$$\frac{dx^{(1)}}{dt} + a x^{(1)} = b$$

$a$ 为发展系数，$b$ 为灰色作用量。

#### 3. 求解参数

用最小二乘法估计：

$$\hat{\beta} = (B^T B)^{-1} B^T Y, \quad \hat{\beta} = [a, b]^T$$

#### 4. 预测公式

$$ 
\hat{x}^{(1)}(k+1) = \left(x^{(0)}(1) - \frac{b}{a}\right) e^{-ak} + \frac{b}{a}
$$

累减还原得原始数据预测值：

$$ 
\hat{x}^{(0)}(k+1) = \hat{x}^{(1)}(k+1) - \hat{x}^{(1)}(k)
$$

#### 5. 模型检验

| 指标 | 计算 | 好 | 合格 | 勉强 | 不合格 |
|------|------|----|------|------|--------|
| 后验差比 $C$ | $S_2/S_1$ | <0.35 | <0.50 | <0.65 | ≥0.65 |
| 小误差概率 $P$ | 见公式 | >0.95 | >0.80 | >0.70 | ≤0.70 |

## 🎯 适用场景

| 问题类型 | 具体例子 |
|---------|---------|
| **小样本预测**（数据量 ≥ 4 即可） | 3~5 年经济指标预测 |
| 短期趋势预测 | 下一年度的销量、产值预测 |
| 缺乏先验信息的场景 | 新产品的市场需求预测 |

**局限：** 只适合**短期**预测（一般 2~3 步），**指数增长**趋势，对波动数据效果差。

## 💻 使用方法 (Python)

```python
import numpy as np

def gm11(data, predict_steps=5):
    """灰色预测 GM(1,1)"""
    n = len(data)
    # 累加生成
    x1 = np.cumsum(data)
    # 邻均值序列
    z1 = (x1[:-1] + x1[1:]) / 2
    # 构造 B, Y
    B = np.vstack([-z1, np.ones(n-1)]).T
    Y = data[1:]
    # 最小二乘
    a, b = np.linalg.inv(B.T @ B) @ B.T @ Y
    # 预测
    pred_x1 = [(data[0] - b/a) * np.exp(-a * k) + b/a for k in range(n + predict_steps)]
    pred_x0 = [pred_x1[0]] + [pred_x1[i] - pred_x1[i-1] for i in range(1, len(pred_x1))]
    return np.array(pred_x0[:predict_steps])

# 示例
data = np.array([2.87, 3.28, 3.68, 4.19, 4.69])
pred = gm11(data, predict_steps=3)
print(f"预测值: {pred.round(3)}")
```
