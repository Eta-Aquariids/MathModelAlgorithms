## 📖 算法原理

**线性回归** 假设因变量 $y$ 与自变量 $x_1, \ldots, x_p$ 之间存在线性关系：

$$
y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_p x_p + \varepsilon
$$

**最小二乘法**求解参数，使残差平方和最小：

$$
\hat{\mathbf{\beta}} = \arg\min \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

**矩阵形式的解析解：** $\hat{\mathbf{\beta}} = (X^T X)^{-1} X^T \mathbf{y}$

### 模型评估

| 指标 | 公式 | 含义 |
|------|------|------|
| $R^2$ | $1 - \text{SSE}/\text{SST}$ | 自变量解释因变量变异的比例 |
| 调整 $R^2$ | $1 - \frac{\text{SSE}/(n-p-1)}{\text{SST}/(n-1)}$ | 惩罚变量过多 |
| $F$ 检验 | — | 检验模型整体显著性 |
| $t$ 检验 | — | 检验单个系数的显著性 |

## 🎯 适用场景

| 问题类型 | 具体例子 |
|---------|---------|
| 因果分析 | 广告投入对销量的影响 |
| 趋势预测 | 根据历史数据预测未来值 |
| 因素分析 | 哪些因素显著影响结果 |

**前提假设：** 线性、独立性、同方差性、正态性。

---

## 💻 使用方法 (Python)

```python
from sklearn.linear_model import LinearRegression
import numpy as np

X = np.random.rand(100, 3)
y = 2 + 3*X[:,0] - 1.5*X[:,1] + 0.5*X[:,2] + np.random.randn(100)*0.1

model = LinearRegression()
model.fit(X, y)

print(f"截距: {model.intercept_:.3f}")
print(f"系数: {model.coef_.round(3)}")
print(f"R²: {model.score(X, y):.4f}")
```
