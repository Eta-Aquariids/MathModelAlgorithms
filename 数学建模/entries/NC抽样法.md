## 📖 算法原理

**NC抽样法**即 **(n, c) 计数标准型抽样检验方案**，是统计质量控制中最基础、应用最广泛的固定样本量计数抽样方法。所谓"计数"，是指仅判定样品"合格/不合格"两类结果。

### 基本思想

从批量为 $N$ 的产品中随机抽取 $n$ 个样品进行检测。设样品中的不合格品数为 $d$，预先设定合格判定数 $c$（也称接收数），则判定规则为：

$$
\boxed{\begin{cases}
d \leq c & \Rightarrow \text{接收该批} \\
d > c & \Rightarrow \text{拒收该批}
\end{cases}}
$$

"NC" 即代表 $(n, c)$ 两个核心参数——**N** = 样本量，**C** = 合格判定数。

### 核心参数详解

| 符号 | 名称 | 含义 | 典型取值 |
|------|------|------|---------|
| $n$ | 样本量 | 从批中随机抽取的样品数量 | 由计算确定 |
| $c$ | 合格判定数 | 允许的最大不合格品数 | 0, 1, 2, 3, ... |
| $N$ | 批量 | 产品总数（大时影响可忽略） | — |
| $p$ | 批不合格品率 | 批中不合格品所占比例 | 未知，待推断 |
| $p_0$ | **合格质量水平 (AQL)** | 生产方认为满意的质量水平 | 0.01~0.05 |
| $p_1$ | **极限质量水平 (LQL)** | 使用方不能接受的质量水平 | 0.05~0.10 |
| $\alpha$ | **生产方风险** | 当 $p=p_0$ 时批被误拒的概率 | 通常取 0.05 |
| $\beta$ | **使用方风险** | 当 $p=p_1$ 时批被误收的概率 | 通常取 0.10 |

### 抽检特性曲线（OC 曲线）

OC 曲线（Operating Characteristic Curve）是评价抽样方案性能的核心工具。它描绘了**批真实不合格品率 $p$** 与**批被接收概率 $P_a$** 之间的函数关系：

$$
P_a(p) = P(d \leq c) = \sum_{d=0}^{c} \binom{n}{d} p^d (1-p)^{n-d}
$$

OC 曲线的几个关键点：

$$
\begin{aligned}
P_a(0) &= 1 && \text{（无不合格品，必然接收）} \\
P_a(p_0) &= 1 - \alpha && \text{（质量合格时以高概率接收）} \\
P_a(p_1) &= \beta && \text{（质量不合格时以低概率接收）} \\
P_a(1) &= 0 && \text{（全不合格，必然拒收）}
\end{aligned}
$$

**OC 曲线的斜率**反映了方案的鉴别力：曲线越陡峭，方案区分好批与坏批的能力越强。

### 方案设计原理

抽样方案设计的核心是求解以下方程组，得到满足双方风险要求的 $(n, c)$：

$$
\begin{cases}
\text{当 } p = p_0: \quad 1 - P_a(p_0) = \alpha \quad \Rightarrow \quad \displaystyle\sum_{d=c+1}^{n} \binom{n}{d} p_0^d (1-p_0)^{n-d} = \alpha \\
\text{当 } p = p_1: \quad P_a(p_1) = \beta \quad \Rightarrow \quad \displaystyle\sum_{d=0}^{c} \binom{n}{d} p_1^d (1-p_1)^{n-d} = \beta
\end{cases}
$$

由于 $n$ 和 $c$ 均为整数，通常无法精确满足，实际取最接近的解。

## 🎯 适用场景

| 适用问题类型 | 具体例子 |
|-------------|---------|
| 来料检验（IQC） | 供应商交付的元器件批次验收 |
| 出厂检验（OQC） | 成品出库前的最终质量把关 |
| 工序间半成品验收 | 上道工序转下道工序的质量确认 |
| 供需双方质量仲裁 | 合同约定的验收抽样方案 |

**数据要求：**
- **数据类型：** 离散计数数据，每个样品只判"合格/不合格"
- **数据量要求：** 批量 $N$ 不宜太小（一般 $N \geq 10n$），以保证抽样代表性
- **前提假设：**
  - 抽样为简单随机抽样
  - 各样品质量相互独立
  - 批量内质量均匀

## 📋 详细算法步骤

### 步骤 1：确定质量参数

供需双方协商确定以下四个关键参数：
- $p_0$（AQL）：合格质量水平，如 1%
- $p_1$（LQL）：极限质量水平，如 5%
- $\alpha$：生产方风险，通常取 0.05
- $\beta$：使用方风险，通常取 0.10

> **经验：** $p_1 / p_0$ 的比值反映了方案的鉴别力需求。比值越小（如 $p_1/p_0 = 2$），需要越大的样本量。

### 步骤 2：求解抽样方案 $(n, c)$

**方法一：查标准表（推荐）**

根据 $p_0$、$p_1$ 查国家标准 GB/T 13262《不合格品率的计数标准型一次抽样检验程序及抽样表》，直接得到 $(n, c)$。

**方法二：数值计算**

通过编程迭代搜索满足风险要求的 $(n, c)$：

```
对 n 从 1 递增：
  对 c 从 0 到 n-1：
    计算 Pa(p0) = P(d ≤ c | p0)
    计算 Pa(p1) = P(d ≤ c | p1)
    若 1-Pa(p0) ≤ α 且 Pa(p1) ≤ β → 找到可行方案
```

### 步骤 3：实施抽样检验

从批中随机抽取 $n$ 个样品，逐个检测并记录不合格品数 $d$。

### 步骤 4：批判定

比较 $d$ 与 $c$：
- $d \leq c$：**接收**该批产品
- $d > c$：**拒收**该批产品

### 步骤 5：绘制 OC 曲线（可选但推荐）

计算并绘制 OC 曲线，直观评估方案的鉴别力。同时可计算 **平均出厂质量 (AOQ)** 和 **平均抽样量 (ATI)** 等指标。

### 补充：平均出厂质量 (AOQ)

对于经过抽样检验后的产品批，其平均出厂不合格品率为：

$$
AOQ = \frac{P_a(p) \cdot p \cdot (N - n)}{N}
$$

当 $N$ 远大于 $n$ 时，近似为 $AOQ \approx P_a(p) \cdot p$。

---

## ⚖️ 优缺点

| ✅ 优点 | ❌ 缺点 |
|--------|--------|
| 操作规则简单，一线检验员易执行 | 固定样本量，对优质批和劣质批抽样量相同，不够经济 |
| 理论基础成熟，OC 曲线直观易懂 | 未利用历史质量信息（调整型方案可弥补） |
| 有国家标准（GB/T 13262）可查表使用 | 对 $p_0$ 和 $p_1$ 的设定较敏感 |
| 同时控制生产方和使用方双方风险 | 对小批量产品不适用 |
| 适用于各种计数型质量特性 | 不能区分"轻微不合格"和"严重不合格" |

## 💻 使用方法 (Python)

### 1. 计算 OC 曲线

```python
import numpy as np
from scipy.stats import binom

def oc_curve(n, c, p_values):
    """
    计算 (n,c) 抽样方案的 OC 曲线
    
    参数:
        n: 样本量
        c: 合格判定数
        p_values: 不合格品率数组
    返回:
        Pa: 接收概率数组
    """
    Pa = []
    for p in p_values:
        prob = binom.cdf(c, n, p)  # P(d ≤ c)
        Pa.append(prob)
    return np.array(Pa)

# 示例：n=100, c=3 的方案
p_vals = np.linspace(0, 0.12, 100)
Pa = oc_curve(100, 3, p_vals)

# 验证风险
p0, p1 = 0.01, 0.05
print(f"p=p0 时接收概率: {binom.cdf(3, 100, p0):.4f} (生产方风险={1-binom.cdf(3, 100, p0):.4f})")
print(f"p=p1 时接收概率: {binom.cdf(3, 100, p1):.4f} (使用方风险={binom.cdf(3, 100, p1):.4f})")
```

### 2. 搜索最优方案

```python
def find_sampling_plan(p0, p1, alpha=0.05, beta=0.10, max_n=1000):
    """
    搜索满足风险要求的 (n, c) 抽样方案
    
    返回:
        (n, c, Pa_p0, Pa_p1) 或 None（未找到）
    """
    best = None
    min_n = float('inf')
    
    for n in range(1, max_n + 1):
        for c in range(0, n):
            Pa_p0 = binom.cdf(c, n, p0)
            Pa_p1 = binom.cdf(c, n, p1)
            
            if (1 - Pa_p0 <= alpha) and (Pa_p1 <= beta):
                if n < min_n:
                    min_n = n
                    best = (n, c, Pa_p0, Pa_p1)
                    break  # 对当前 n，最小 c 即最优
    return best

# 实例：p0=0.01, p1=0.05, alpha=0.05, beta=0.10
plan = find_sampling_plan(p0=0.01, p1=0.05)
if plan:
    n, c, Pa_p0, Pa_p1 = plan
    print(f"最优方案: n={n}, c={c}")
    print(f"当 p=p0(0.01): Pa={Pa_p0:.4f}, 生产方风险={1-Pa_p0:.4f}")
    print(f"当 p=p1(0.05): Pa={Pa_p1:.4f}, 使用方风险={Pa_p1:.4f}")
```

### 3. 绘制 OC 曲线（可视化）

```python
import matplotlib.pyplot as plt

p_vals = np.linspace(0, 0.12, 100)
Pa = oc_curve(n, c, p_vals)

plt.figure(figsize=(8, 5))
plt.plot(p_vals, Pa, 'b-', linewidth=2, label=f'OC曲线 (n={n}, c={c})')
plt.axvline(x=p0, color='green', linestyle='--', label=f'p0={p0}')
plt.axvline(x=p1, color='red', linestyle='--', label=f'p1={p1}')
plt.axhline(y=1-alpha, color='green', linestyle=':', label=f'1-α={1-alpha}')
plt.axhline(y=beta, color='red', linestyle=':', label=f'β={beta}')
plt.xlabel('批不合格品率 p')
plt.ylabel('接收概率 Pa(p)')
plt.title('OC 曲线图')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 📊 实例应用

### 实例 1：来料检验

某电子厂收到一批元器件，批量 $N=2000$。供需双方约定：
- AQL = 1.0%（$p_0=0.01$），$\alpha=0.05$
- LQL = 5.0%（$p_1=0.05$），$\beta=0.10$

**解：** 查 GB/T 13262 或编程计算得 $(n, c) = (200, 5)$。
- 抽样 200 个，若不合格数 $\leq 5$ 则接收，否则拒收。
- 当实际质量 $p=0.01$ 时，接收概率约 95%；当 $p=0.05$ 时，接收概率约 10%。

### 实例 2：生产方风险与使用方风险的权衡

给定 $p_0=0.01, p_1=0.06$，不同的 $(n, c)$ 方案对比：

| 方案 (n, c) | $P_a(p_0)$ | 生产方风险 | $P_a(p_1)$ | 使用方风险 |
|------------|-----------|-----------|-----------|-----------|
| (80, 2) | 0.953 | 0.047 | 0.288 | 0.288 ❌ |
| (150, 4) | 0.964 | 0.036 | 0.118 | 0.118 ❌ |
| (200, 5) | 0.957 | 0.043 | 0.092 | 0.092 ✅ |
| (300, 7) | 0.954 | 0.046 | 0.083 | 0.083 ✅ |

可见，样本量越大，方案的鉴别力越强（OC 曲线越陡峭），但检验成本也越高。

## 🔗 关联算法

- [[声称质量水平检验法]] — 仅控制生产方风险的简化方案，适用于验证性场景

## 📝 补充说明

### 关于 OC 曲线的鉴别力

OC 曲线的鉴别力可以用 **OR 比**（Odds Ratio）衡量：

$$
OR = \frac{p_{0.50}}{p_{0.10}}
$$

其中 $p_{0.50}$ 是接收概率为 50% 时对应的不合格品率，$p_{0.10}$ 是接收概率为 10% 时对应的不合格品率。OR 越接近 1，鉴别力越强。

### 实际应用注意

1. **NC 抽样法假设批量较大**：当 $N$ 较小时（如 $N < 10n$），应使用有限总体修正或超几何分布计算 OC 曲线
2. **不适用的情况**：对价值极高或极低的产品（前者应全检，后者可放宽）
3. **与调整型方案的区别**：标准型（NC）不依赖历史数据，调整型（GB/T 2828）根据历史质量切换正常/加严/放宽检验
