## 📖 算法原理

**有向无环图 (Directed Acyclic Graph, DAG)** 是没有环的有向图，是图论中最常用的结构之一，因为现实中的依赖关系天然就是无环的。

---

### 一、拓扑排序

将 DAG 的所有顶点排成一个线性序列，使得对于每条有向边 $u \to v$，$u$ 都排在 $v$ 的前面。

#### Kahn 算法（贪心法）

```
1. 计算所有顶点的入度
2. 将入度为 0 的顶点入队列
3. 当队列非空：
   a. 取出顶点 u，加入拓扑序列
   b. 对 u 的每个邻接 v，入度减 1
   c. 若 v 的入度变为 0，入队列
4. 若拓扑序列长度 < 顶点数 → 说明有环
```

**时间复杂度：** $O(V+E)$

---

### 二、DAG 上的最短/最长路径

DAG 的一个关键性质：用拓扑排序可以在 $O(V+E)$ 时间内求出**单源最短/最长路径**（比 Dijkstra 更快，且支持负权边）。

```
1. 对 DAG 做拓扑排序
2. 按拓扑序依次处理每个顶点 u：
    对 u 的每个邻接 v：
      若 dist[u] + w(u,v) > dist[v] → 更新（最长路径）
```

---

### 三、关键路径法 (CPM)

关键路径是项目中**耗时最长的路径**，决定了项目的最短完工时间。

| 概念 | 含义 | 公式 |
|------|------|------|
| 最早开始时间 $ES$ | 活动最早能开始的时间 | $ES = \max(ES_{前驱} + 持续时间)$ |
| 最晚开始时间 $LS$ | 不影响工期的前提下最晚开始时间 | $LS = \min(LS_{后继} - 持续时间)$ |
| 浮动时间 $TF$ | 可延迟的时间 | $TF = LS - ES$ |
| **关键路径** | $TF = 0$ 的活动组成的路径 | 浮动时间为 0 |

## 💻 使用方法 (Python)

### 拓扑排序 (Kahn 算法)

```python
from collections import deque

def topological_sort(graph):
    """
    graph: 邻接表 {u: [v1, v2, ...]}
    返回: 拓扑序列列表，若有环返回 None
    """
    n = len(graph)
    in_deg = {u: 0 for u in graph}
    for u in graph:
        for v in graph[u]:
            in_deg[v] = in_deg.get(v, 0) + 1
    
    q = deque([u for u in graph if in_deg[u] == 0])
    result = []
    
    while q:
        u = q.popleft()
        result.append(u)
        for v in graph[u]:
            in_deg[v] -= 1
            if in_deg[v] == 0:
                q.append(v)
    
    if len(result) != n:
        return None  # 有环
    return result

# 示例：课程先修关系
graph = {
    '算法': ['数据结构', '机器学习'],
    '数据结构': ['编程入门'],
    '机器学习': ['深度学习'],
    '编程入门': [],
    '深度学习': []
}
order = topological_sort(graph)
print("学习顺序:", order)
```

### 关键路径法

```python
def critical_path(tasks, durations, deps):
    """
    tasks: 任务列表
    durations: 各任务持续时间 {task: time}
    deps: 依赖关系 {task: [依赖的任务列表]}
    返回: 关键路径、最短工期
    """
    n = len(tasks)
    # 正向：最早开始时间
    ES = {t: 0 for t in tasks}
    topo = topological_sort({t: deps[t] for t in tasks})
    
    for t in topo:
        for dep in deps[t]:
            ES[t] = max(ES[t], ES[dep] + durations[dep])
    
    # 总工期
    total = max(ES[t] + durations[t] for t in tasks)
    
    # 反向：最晚开始时间
    LS = {t: total - durations[t] for t in tasks}
    for t in reversed(topo):
        for dep in deps[t]:
            LS[dep] = min(LS[dep], LS[t] - durations[dep])
    
    # 浮动时间 = 0 的为关键路径
    critical = [t for t in tasks if LS[t] - ES[t] == 0]
    
    return critical, total

# 示例：工程项目
tasks = ['A', 'B', 'C', 'D', 'E']
durations = {'A': 3, 'B': 2, 'C': 5, 'D': 4, 'E': 6}
deps = {'A': [], 'B': [], 'C': ['A'], 'D': ['A', 'B'], 'E': ['C', 'D']}

critical, total = critical_path(tasks, durations, deps)
print(f"关键路径: {critical}")
print(f"最短工期: {total}")
```

### DAG 上的最长路径

```python
def longest_path_dag(graph, weights, start):
    """
    graph: 邻接表 {u: [v, ...]}
    weights: 边权 {(u,v): w}
    start: 起点
    返回: 从 start 到各点的最长距离
    """
    topo = topological_sort(graph)
    dist = {v: float('-inf') for v in graph}
    dist[start] = 0
    
    # 按拓扑序处理
    for u in topo:
        if dist[u] != float('-inf'):
            for v in graph[u]:
                w = weights.get((u, v), 0)
                if dist[u] + w > dist[v]:
                    dist[v] = dist[u] + w
    return dist
```

## 📊 实例应用

### 实例：项目管理中的关键路径

一个工程包含 6 个任务：

```
A(3天) ──→ C(5天) ──→ E(6天)
  \                 /
   ↘→ D(4天) →──↗
B(2天) ↗
```

| 任务 | 依赖 | 最早开始 | 最晚开始 | 浮动 | 关键？ |
|:----:|:----:|:-------:|:-------:|:---:|:-----:|
| A | 无 | 0 | 0 | 0 | ✅ |
| B | 无 | 0 | 3 | 3 | |
| C | A | 3 | 3 | 0 | ✅ |
| D | A, B | 4 | 5 | 1 | |
| E | C, D | 8 | 8 | 0 | ✅ |

**关键路径：** A → C → E，**最短工期：** 14 天

> 关键路径上的任务一天都不能延迟，否则整个项目延期。

## 🔗 关联算法

- [[Dijkstra 最短路径]] — 有环图的最短路径，但 DAG 可以用拓扑排序更高效
- [[动态规划 (DP)]] — DAG 上的最长路径本质就是 DP
- **最小生成树** — 无向连通图，DAG 是有向无环

## 📝 补充说明

- DAG 上的最长路径是**多项式时间可解的**（用拓扑排序 + DP），而一般图上的最长路径是 **NP-hard**
- 这就是为什么很多问题要利用 DAG 结构——可以高效求解
- 在数学建模中，**关键路径法 (CPM)** 和 **计划评审技术 (PERT)** 是项目管理类问题的标准工具
