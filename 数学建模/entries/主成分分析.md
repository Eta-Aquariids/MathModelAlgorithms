## 📖 算法原理

**主成分分析（PCA）** 是最常用的**无监督线性降维**方法，通过正交变换将 $p$ 个相关变量转换为 $q$ 个**不相关的综合变量（主成分）**，使第一个主成分的方差最大。

### 核心思想

找到数据方差最大的方向（第一主成分），然后在与之正交的方向上找方差次大的方向（第二主成分），依此类推。

### 算法步骤

#### 1. 数据中心化

$$\tilde{x}_{ij} = x_{ij} - \bar{x}_j$$

#### 2. 计算协方差矩阵

$$S = \frac{1}{n-1} \tilde{X}^T \tilde{X}$$

#### 3. 特征值分解

$$S \mathbf{v}_i = \lambda_i \mathbf{v}_i$$

特征值 $\lambda_i$ 表示第 $i$ 个主成分的**方差贡献度**。

#### 4. 确定主成分个数

**累计方差贡献率：**

$$\text{贡献率}_k = \frac{\sum_{i=1}^{k} \lambda_i}{\sum_{i=1}^{p} \lambda_i}$$

通常取累计贡献率 $\geq 85\%$ 的前 $k$ 个主成分。

#### 5. 降维投影

$$Z = \tilde{X} V_k$$

其中 $V_k$ 为前 $k$ 个特征向量组成的矩阵。

## 🎯 适用场景

| 问题类型 | 具体例子 |
|---------|---------|
| **高维数据可视化** | 10+ 维数据降至 2D/3D 绘图 |
| **消除多重共线性** | 回归分析前用 PCA 处理高度相关变量 |
| **特征压缩** | 压缩变量数量，减少模型过拟合 |
| **综合评价** | 用第一主成分的得分作为综合得分 |

**前提：** PCA 假设数据服从**线性流形**，对非线性数据效果有限。

---

## 💻 使用方法 (Python)

```python
from sklearn.decomposition import PCA
import numpy as np

X = np.random.rand(50, 10)  # 50个样本, 10维

pca = PCA(n_components=0.85)  # 保留 85% 方差
X_pca = pca.fit_transform(X)

print(f"降维后维度: {X_pca.shape[1]}")
print(f"各主成分方差贡献率: {pca.explained_variance_ratio_.round(4)}")
print(f"累计贡献率: {pca.explained_variance_ratio_.cumsum().round(4)}")
```
