## 📖 算法原理

**动态规划（Dynamic Programming, DP）** 是一种将**多阶段决策问题**分解为一系列单阶段子问题的优化方法，由 Richard Bellman 于 1950 年代创立。其核心思想是**贝尔曼最优性原理**：

> 无论初始状态和初始决策如何，后续的决策必须构成一个以当前状态为起点的最优策略。

### 核心要素

DP 模型的四个核心要素：

| 要素 | 含义 | 例子（最短路径） |
|------|------|----------------|
| **阶段** $k$ | 决策的步骤序号 | 走过的步数 |
| **状态** $\mathbf{s}_k$ | 当前所处的状况 | 当前所在城市 |
| **决策** $u_k$ | 当前阶段的选择 | 选择下一个城市 |
| **状态转移方程** | 下一状态 = 当前状态 + 决策 | $s_{k+1} = s_k + u_k$ |
| **最优值函数** $V_k(\mathbf{s}_k)$ | 从当前状态到终点的最优累积收益 | 从当前城市到终点的最短距离 |

### 贝尔曼方程（递归关系）

DP 的核心是**贝尔曼方程**，描述了阶段间的递推关系：

$$
\boxed{V_k(\mathbf{s}_k) = \min_{u_k \in U_k(\mathbf{s}_k)} \left\{ C_k(\mathbf{s}_k, u_k) + V_{k+1}(\mathbf{s}_{k+1}) \right\}}
$$

其中：
- $V_k(\mathbf{s}_k)$：从状态 $\mathbf{s}_k$ 到终点的最优值
- $C_k(\mathbf{s}_k, u_k)$：当前阶段的即时成本（收益）
- $V_{k+1}(\mathbf{s}_{k+1})$：下一阶段到终点的最优值

**边界条件：** $V_{N}(\mathbf{s}_N)$ 已知（终点的值）

### 求解方向

| 方向 | 做法 | 适用场景 |
|------|------|---------|
| **正向递推** | 从第一阶段到最终阶段 | 已知初始状态 |
| **逆向递推** | 从最终阶段到第一阶段（更常用） | 已知目标状态 |

### 适用条件

一个优化问题能用 DP 求解需要满足：

1. **最优子结构：** 全局最优解包含子问题的最优解
2. **重叠子问题：** 不同路径会到达同一个子问题（可用记忆化避免重复计算）
3. **无后效性：** 未来决策只依赖于当前状态，不依赖于到达该状态的路径

## 🎯 适用场景

| 问题类型 | 具体例子 |
|---------|---------|
| **最短路径** | 多阶段网络中的最短路线 |
| **背包问题** | 0-1 背包、完全背包、多重背包 |
| **资源分配** | 有限资金在多个项目中分配使总收益最大 |
| **序列决策** | 生产与库存决策、设备更新问题 |
| **序列比对** | DNA 序列全局/局部比对（Needleman-Wunsch） |
| **编辑距离** | 两个字符串的最小编辑次数 |

**数据要求：**
- 状态空间大小决定计算量——**维数灾难**是 DP 的最大限制
- 要求最优子结构 + 无后效性

---

## 📋 算法步骤

1. **划分阶段：** 将问题分解为若干有序的阶段
2. **定义状态：** 确定每个阶段的状态变量 $\mathbf{s}_k$
3. **确定决策：** 明确每个阶段的可行决策集合 $U_k(\mathbf{s}_k)$
4. **建立状态转移方程：** $\mathbf{s}_{k+1} = T_k(\mathbf{s}_k, u_k)$
5. **确定边界条件：** 初始或最终阶段的指标值
6. **建立贝尔曼方程：** 递推关系
7. **递推求解：** 从边界出发，逆向或正向递推

---

## ⚖️ 优缺点

| ✅ 优点 | ❌ 缺点 |
|--------|--------|
| 能处理阶段/顺序决策问题，逻辑清晰 | **维数灾难：** 状态变量每增加一维，计算量指数增长 |
| 对目标函数和约束无凸性/线性要求 | 需要问题有**最优子结构**和**无后效性** |
| 一次求解即得所有子问题的最优解 | 状态定义需要一定技巧 |
| 适合路径规划和资源分配类问题 | 不适用于连续状态空间（需离散化） |

## 💻 使用方法 (Python)

### 示例：0-1 背包问题

```python
def knapsack_01(weights, values, capacity):
    """
    0-1 背包问题的动态规划求解
    
    参数:
        weights: 物品重量列表
        values: 物品价值列表
        capacity: 背包容量
    返回:
        max_value: 最大总价值
        selected: 选中的物品索引
    """
    n = len(weights)
    # dp[i][c]: 前 i 个物品中，容量 c 的最大价值
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        w = weights[i - 1]
        v = values[i - 1]
        for c in range(1, capacity + 1):
            if w > c:
                dp[i][c] = dp[i - 1][c]
            else:
                dp[i][c] = max(dp[i - 1][c], dp[i - 1][c - w] + v)
    
    # 回溯找出选中的物品
    selected = []
    c = capacity
    for i in range(n, 0, -1):
        if dp[i][c] != dp[i - 1][c]:
            selected.append(i - 1)
            c -= weights[i - 1]
    
    return dp[n][capacity], selected

# 使用示例
weights = [2, 3, 4, 5]
values = [3, 4, 5, 6]
capacity = 8

max_val, selected = knapsack_01(weights, values, capacity)
print(f"最大价值: {max_val}")
print(f"选中物品: {[f"物品{i+1}" for i in selected]}")
```

### 示例：最短路径（多阶段决策）

```python
def shortest_path(stages):
    """
    多阶段最短路径问题的 DP 求解
    
    参数:
        stages: 阶段间距离矩阵列表
    返回:
        最短路径长度和路径
    """
    n = len(stages)  # 阶段数
    # 逆向递推
    dp = [{'cost': float('inf'), 'next': -1} for _ in range(n + 1)]
    dp[n]['cost'] = 0  # 终点
    
    for k in range(n - 1, -1, -1):
        for i, costs in enumerate(stages[k]):
            for j, cost in enumerate(costs):
                if cost + dp[j]['cost'] < dp[i]['cost']:
                    dp[i]['cost'] = cost + dp[j]['cost']
                    dp[i]['next'] = j
    
    return dp[0]['cost']

# 示例：3 阶段最短路径
stages = [
    # 阶段0: 从起点到各中间点
    [(2, 4), (3, 2)],  # 从起点...这个例子略复杂
]
```

## 📊 实例应用：数学建模中的典型问题

| 问题 | DP 解法 |
|------|--------|
| **设备更新问题** | 状态 = 设备已用年限，决策 = 保留/更换 |
| **生产-库存计划** | 状态 = 期末库存量，决策 = 本期产量 |
| **投资组合优化** | 状态 = 剩余资金，决策 = 投资到各项目金额 |
| **最长公共子序列** | 状态 = 两个序列的当前位置 |

## 🔗 关联算法

- [[线性规划 (LP)]] — 另一种优化范式，DP 适合顺序决策，LP 适合资源分配
- [[整数规划 (IP)]] — 某些 DP 问题（如背包）也可用 IP 求解
- Dijkstra 算法 — 最短路径问题的 DP 特例（单源、非负权重）

## 📝 补充说明

- DP 的**维数灾难**是其最大的实际限制——状态变量的数目不能太多
- 数学建模中常用 DP 处理**时间序列决策**问题（如生产安排、设备更新）
- 连续状态的 DP 可通过**离散化**近似求解，但精度与计算量需要权衡
- 与**分治**的区别：DP 的子问题重叠，分治的子问题不重叠
