## 📖 算法原理

**最小生成树 (MST)** 在一个带权无向连通图中找一棵包含所有顶点的树，使所有边的权值之和最小。

### Prim 算法（加点法）

从一个顶点出发，每次将**离当前树最近的顶点**加入树中。

- 时间复杂度：$O(V^2)$（朴素）/$O(E\log V)$（堆优化）
- 适用于**稠密图**

### Kruskal 算法（加边法）

将所有边按权值从小到大排序，依次加入，若加入后不形成环则保留。

- 时间复杂度：$O(E\log E)$
- 适用于**稀疏图**

```
Prim:    从点出发，每次找最近的邻居加入
Kruskal: 从边出发，每次选最短的边，不形成环就加
```

### 核心性质

**切割性质：** 若一条边的权值小于所有连接两个"切割"的边，则它一定在某个 MST 中。

## 💻 使用方法 (Python)

### Kruskal 算法

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px != py:
            self.parent[px] = py
            return True
        return False

def kruskal(n, edges):
    """edges: [(u, v, weight), ...]，节点 0~n-1"""
    edges.sort(key=lambda e: e[2])
    uf = UnionFind(n)
    mst = []
    total = 0
    for u, v, w in edges:
        if uf.union(u, v):
            mst.append((u, v, w))
            total += w
    return mst, total

# 示例
edges = [(0,1,4),(0,2,3),(1,2,1),(1,3,2),(2,3,4)]
mst, total = kruskal(4, edges)
print(f"MST: {mst}, 总权值: {total}")
```

### Prim 算法

```python
import heapq

def prim(graph, start=0):
    """graph: 邻接表 [(邻居, 权重), ...]"""
    n = len(graph)
    visited = [False] * n
    pq = [(0, start, -1)]  # (权重, 节点, 父节点)
    mst = []
    total = 0
    
    while pq:
        w, u, parent = heapq.heappop(pq)
        if visited[u]:
            continue
        visited[u] = True
        total += w
        if parent != -1:
            mst.append((parent, u, w))
        for v, w2 in graph[u]:
            if not visited[v]:
                heapq.heappush(pq, (w2, v, u))
    
    return mst, total
```
