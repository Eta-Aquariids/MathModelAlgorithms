## 📖 算法原理

**层次分析法（AHP）** 是一种将**定性**与**定量**相结合的多准则决策方法，由美国运筹学家 Saaty 于 1970 年代提出。核心思想：将一个复杂决策问题分解为**目标层—准则层—方案层**的层次结构，通过两两比较确定各因素权重。

### 核心步骤

#### 1. 建立层次结构

```
目标层:             选择最优方案
                    /    |    \
准则层:       经济性  技术性  环保性
                / \    / \    / \
方案层:       方案A  方案B  方案C
```

#### 2. 构造判断矩阵

对同一层因素两两比较相对重要性，使用 **1-9 标度法**：

| 标度 | 含义 |
|------|------|
| 1 | 同等重要 |
| 3 | 稍微重要 |
| 5 | 明显重要 |
| 7 | 强烈重要 |
| 9 | 极端重要 |
| 2,4,6,8 | 相邻标度中间值 |

判断矩阵 $A = (a_{ij})_{n \times n}$，满足：
- $a_{ij} > 0$，$a_{ji} = 1/a_{ij}$
- $a_{ii} = 1$

#### 3. 计算权重向量

**特征向量法（推荐）：** 求解 $A\mathbf{w} = \lambda_{\max}\mathbf{w}$，归一化后即为权重。

**几何平均法（近似）：**

$$
w_i = \frac{\left(\prod_{j=1}^{n} a_{ij}\right)^{1/n}}{\sum_{k=1}^{n}\left(\prod_{j=1}^{n} a_{kj}\right)^{1/n}}
$$

#### 4. 一致性检验

计算一致性指标和比率：

$$
\text{CI} = \frac{\lambda_{\max} - n}{n - 1}, \quad \text{CR} = \frac{\text{CI}}{\text{RI}}
$$

其中 RI 为随机一致性指标（查表）。当 $\text{CR} < 0.10$ 时，判断矩阵一致性可接受。

## 💻 使用方法 (Python)

```python
import numpy as np

def ahp_weights(matrix):
    """计算 AHP 权重及一致性检验"""
    n = len(matrix)
    # 特征向量法求权重
    eigvals, eigvecs = np.linalg.eig(matrix)
    max_idx = np.argmax(eigvals)
    w = np.real(eigvecs[:, max_idx])
    w = w / np.sum(w)
    
    # 一致性检验
    lam = np.real(eigvals[max_idx])
    CI = (lam - n) / (n - 1)
    RI_table = [0, 0, 0.58, 0.90, 1.12, 1.24, 1.32, 1.41, 1.45, 1.49]
    RI = RI_table[n - 1] if n <= 10 else 1.5
    CR = CI / RI if RI > 0 else 0
    
    return w, CR

# 示例：3 个准则的判断矩阵
matrix = np.array([
    [1,   1/3, 1/2],
    [3,   1,   2  ],
    [2,   1/2, 1  ]
])
w, CR = ahp_weights(matrix)
print(f"权重: {w.round(4)}")
print(f"CR = {CR:.4f}，{'一致性可接受' if CR < 0.1 else '需调整矩阵'}")
```
