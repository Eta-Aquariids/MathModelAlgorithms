## 📖 算法原理

**蚁群算法（Ant Colony Optimization, ACO）** 是一种模拟**蚂蚁觅食行为**的群体智能优化算法，由意大利学者 Marco Dorigo 于 1992 年在其博士论文中提出。ACO 特别擅长求解**组合优化问题**，尤其是**路径/图**相关问题。

### 生物类比

自然界中的蚂蚁在觅食时会释放一种化学物质——**信息素（Pheromone）**。蚂蚁走过的路径上会留下信息素，后来的蚂蚁倾向于选择信息素浓度更高的路径。这种**正反馈机制**使群体能逐渐找到从蚁巢到食物源的最短路径。

```
           蚁巢 ───────────────────────→ 食物源
                   ↗  ↗     (短路径)
                 ↗ ↗  (信息素累积快)
    
    短路径 → 蚂蚁往返快 → 信息素累积快 → 更多蚂蚁选择 → 正反馈强化
    长路径 → 蚂蚁往返慢 → 信息素累积慢 → 被逐渐放弃
```

### 数学模型（以 TSP 为例）

设有 $n$ 个城市，$m$ 只蚂蚁。

#### 1. 状态转移概率

蚂蚁 $k$ 在城市 $i$ 时，选择下一个城市 $j$ 的概率：

$$
P_{ij^k = 
\begin{cases}
\dfrac{[\tau_{ij}]^\alpha \cdot [\eta_{ij}]^\beta}{\displaystyle\sum_{l \in J_i^k} [\tau_{il}]^\alpha \cdot [\eta_{il}]^\beta}, & j \in J_i^k \\
0, & \text{否则}
\end{cases}}
$$

其中：

| 符号 | 含义 | 说明 |
|------|------|------|
| $\tau_{ij}$ | 边 $(i,j)$ 上的**信息素浓度** | 路径被选择的"历史吸引力" |
| $\eta_{ij}$ | **启发式信息**，通常 $\eta_{ij} = 1/d_{ij}$ | 路径长度的"即时吸引力" |
| $\alpha$ | **信息素权重** | 控制信息素的影响力 |
| $\beta$ | **启发式信息权重** | 控制启发信息的影响力 |
| $J_i^k$ | 蚂蚁 $k$ 尚未访问的城市集合 | 保证每个城市只去一次 |

#### 2. 信息素更新

每次迭代结束后，更新所有路径上的信息素：

**蒸发（避免陷入局部最优的遗忘机制）：**

$$
\tau_{ij} \leftarrow (1 - \rho) \cdot \tau_{ij}
$$

其中 $\rho \in (0, 1]$ 是**信息素蒸发率**。

**释放（表现好的路径获得奖励）：**

$$
\tau_{ij} \leftarrow \tau_{ij} + \sum_{k=1}^{m} \Delta \tau_{ij}^k
$$

其中 $\Delta \tau_{ij}^k$ 为蚂蚁 $k$ 在边 $(i,j)$ 上释放的信息素量：

$$
\Delta \tau_{ij}^k = 
\begin{cases}
Q / L_k, & \text{蚂蚁 } k \text{ 经过了边 } (i,j) \\
0, & \text{否则}
\end{cases}
$$

- $L_k$：蚂蚁 $k$ 走过的路径总长度
- $Q$：常量（信息素释放总量控制）

> 路径越短 → 每只蚂蚁释放的信息素越多 → 该路径被强化 → 正反馈

#### 3. 完整流程

```
初始化: 每条边设置初始信息素 τ₀
在 n 个城市上放置 m 只蚂蚁

FOR iteration = 1 TO 最大代数:
    FOR 每只蚂蚁 k:
        从随机城市出发
        WHILE 未遍历所有城市:
            按概率 P_ij^k 选择下一个城市
            将所选城市加入禁忌表
        计算路径长度 L_k
    
    更新全局最短路径
    
    FOR 每条边 (i,j):
        信息素蒸发: τ_ij ← (1-ρ) · τ_ij
        FOR 每只蚂蚁 k:
            IF 蚂蚁 k 经过 (i,j):
                信息素释放: τ_ij ← τ_ij + Q/L_k
    
    记录当前最优

RETURN 全局最优路径
```

### ACO 的变体

| 变体 | 改进点 | 特点 |
|------|--------|------|
| **蚁群系统 (ACS)** | 局部信息素更新 + 伪随机选择规则 | 性能最优，最常用 |
| **最大-最小蚁群 (MMAS)** | 限制信息素上下界 $[\tau_{\min}, \tau_{\max}]$ | 避免停滞，防止早熟 |
| **精英蚁群 (EAS)** | 只让最优蚂蚁释放信息素 | 收敛更快 |
| **自适应蚁群** | 动态调整 $\alpha, \beta, \rho$ | 适应不同搜索阶段 |

## 🎯 适用场景

| 问题类型 | 具体例子 |
|---------|---------|
| **旅行商问题 (TSP)** | ACO 最经典的应用，效果极佳 |
| **车辆路径问题 (VRP)** | 物流配送、快递线路优化 |
| **车间调度 (JSP)** | 机器加工工序排序 |
| **图论问题** | 图着色、最短路径、网络路由 |
| **指派问题** | 任务分配、人员排班 |
| **连续优化** | 需离散化或混合其他算法 |

**数据要求：**
- 问题能用**图/网络**结构表示（顶点、边、权重）
- 路径类问题效果最好，通用连续优化不是 ACO 的强项

## 📋 详细算法步骤

### 参数设置指南

| 参数 | 含义 | 影响 | 典型范围 |
|------|------|------|---------|
| $m$ | 蚂蚁数量 | 越多搜索越充分，计算量越大 | $n \sim 2n$（城市数） |
| $\alpha$ | 信息素权重 | 大→正反馈强，易早熟 | $1 \sim 3$ |
| $\beta$ | 启发式权重 | 大→贪心倾向，忽略全局 | $2 \sim 5$ |
| $\rho$ | 蒸发率 | 大→历史快遗忘，探索强 | $0.1 \sim 0.5$ |
| $\tau_0$ | 初始信息素 | 影响搜索初期的探索性 | $Q / L_{\text{greedy}}$ |

### 算法步骤

1. **初始化：** 设置参数，计算城市间距离矩阵，每条边设置初始信息素 $\tau_0$
2. **蚂蚁构造解：** 每只蚂蚁从随机城市出发，按概率转移公式依次选择下一城市，直到所有城市访问完毕
3. **评估路径：** 计算每只蚂蚁的路径长度，更新全局最优
4. **更新信息素：** 先蒸发再释放（每只蚂蚁或仅最优蚂蚁）
5. **终止检查：** 若达到最大迭代次数或最优解连续 $K$ 代无改进则停止
6. **重复 2~5**

---

## ⚖️ 优缺点

| ✅ 优点 | ❌ 缺点 |
|--------|--------|
| **正反馈机制**——好路径被自动强化 | **收敛速度慢**，尤其是早期信息素尚未分化 |
| 适合**路径/图类问题**，设计自然 | 参数较多（$\alpha, \beta, \rho, m$），调参复杂 |
| 有**正反馈+随机性**的平衡 | 不适用于一般的连续优化问题 |
| 天然支持**并行计算**（多只蚂蚁独立） | 对大规模问题，计算时间较长 |
| 能给出**多条满意路径**供选择 | 数学理论基础不如 GA/SA 完善 |

## 💻 使用方法 (Python)

```python
import numpy as np
import random

class AntColonyOptimizer:
    """
    蚁群算法求解 TSP 问题
    """
    def __init__(self, n_ants=20, alpha=1.0, beta=3.0, 
                 rho=0.3, q=100, max_iter=200, elitist=True):
        """
        参数:
            n_ants: 蚂蚁数量
            alpha: 信息素权重
            beta: 启发式信息权重
            rho: 信息素蒸发率
            q: 信息素释放总量
            max_iter: 最大迭代次数
            elitist: 是否只允许最优蚂蚁释放信息素
        """
        self.m = n_ants
        self.alpha = alpha
        self.beta = beta
        self.rho = rho
        self.Q = q
        self.max_iter = max_iter
        self.elitist = elitist
    
    def fit(self, dist_matrix):
        """
        求解 TSP
        
        参数:
            dist_matrix: 距离矩阵 (n x n)
        返回:
            best_path: 最优路径
            best_dist: 最短距离
            history: 收敛曲线
        """
        n = len(dist_matrix)
        tau = np.ones((n, n)) * 0.1  # 初始信息素
        
        # 启发式信息 η = 1/d
        eta = 1.0 / (dist_matrix + 1e-10)
        
        best_path = None
        best_dist = float('inf')
        history = []
        
        for iteration in range(self.max_iter):
            # 每只蚂蚁构造路径
            paths = []
            dists = []
            
            for k in range(self.m):
                path = self._construct_path(n, tau, eta)
                paths.append(path)
                dists.append(self._path_distance(path, dist_matrix))
            
            # 更新全局最优
            min_idx = np.argmin(dists)
            if dists[min_idx] < best_dist:
                best_dist = dists[min_idx]
                best_path = paths[min_idx][:]
            
            history.append(best_dist)
            
            if iteration % 20 == 0:
                print(f"迭代 {iteration:4d}: 当前最优 = {best_dist:.4f}")
            
            # 更新信息素
            # 蒸发
            tau *= (1 - self.rho)
            
            # 释放
            if self.elitist:
                # 仅最优蚂蚁释放
                delta = self.Q / best_dist
                for i in range(n - 1):
                    tau[best_path[i], best_path[i+1]] += delta
                tau[best_path[-1], best_path[0]] += delta
            else:
                # 所有蚂蚁释放
                for k in range(self.m):
                    delta = self.Q / dists[k]
                    for i in range(n - 1):
                        tau[paths[k][i], paths[k][i+1]] += delta
                    tau[paths[k][-1], paths[k][0]] += delta
            
            # 信息素下限（防止完全蒸发）
            tau = np.maximum(tau, 1e-5)
        
        return best_path, best_dist, history
    
    def _construct_path(self, n, tau, eta):
        """一只蚂蚁构造完整路径"""
        start = random.randint(0, n - 1)
        path = [start]
        visited = {start}
        
        for _ in range(n - 1):
            i = path[-1]
            # 未访问城市集合
            candidates = [j for j in range(n) if j not in visited]
            
            # 计算选择概率
            probs = []
            for j in candidates:
                p = (tau[i, j] ** self.alpha) * (eta[i, j] ** self.beta)
                probs.append(p)
            probs = np.array(probs) / sum(probs)
            
            # 轮盘赌选择
            j = np.random.choice(candidates, p=probs)
            path.append(j)
            visited.add(j)
        
        return path
    
    def _path_distance(self, path, dist_matrix):
        """计算路径总长度"""
        dist = 0
        n = len(path)
        for i in range(n - 1):
            dist += dist_matrix[path[i], path[i+1]]
        dist += dist_matrix[path[-1], path[0]]
        return dist


# 使用示例
if __name__ == "__main__":
    # 生成 20 个随机城市
    np.random.seed(42)
    n_cities = 20
    cities = np.random.rand(n_cities, 2) * 100
    
    # 距离矩阵
    dist = np.zeros((n_cities, n_cities))
    for i in range(n_cities):
        for j in range(n_cities):
            dist[i, j] = np.linalg.norm(cities[i] - cities[j])
    
    # 求解
    aco = AntColonyOptimizer(n_ants=20, alpha=1, beta=3, 
                             rho=0.3, max_iter=100, elitist=True)
    best_path, best_dist, _ = aco.fit(dist)
    
    print(f"\n最优路径长度: {best_dist:.4f}")
    print(f"最优路径: {best_path}")
```

## 📊 实例应用

### 实例：ACO vs GA 求解 TSP

| 维度 | ACO | GA |
|------|-----|-----|
| 编码 | 自然（蚂蚁直接在图上行走） | 需要排列编码 + PMX 交叉 |
| 正反馈 | 强（信息素累积） | 弱（依赖选择压力） |
| 小规模 TSP | 很快收敛 | 较慢 |
| 大规模 TSP（>100 城市） | 需大量蚂蚁，计算大 | 更灵活 |
| 收敛特性 | 先探索后快速收敛 | 逐渐收敛 |

## 🔗 关联算法

- [[模拟退火算法 (SA)]] — 单点搜索，可作为 ACO 的局部优化步骤
- [[粒子群算法 (PSO)]] — 另一群体智能算法，侧重连续优化
- [[遗传算法 (GA)]] — 也是种群算法，但依赖交叉变异，信息共享方式不同
- **人工蜂群 (ABC)** — 模拟蜜蜂采蜜行为的群体智能算法

## 📝 补充说明

- ACO **最适合路径/网络类组合优化问题**（TSP、VRP、网络路由），这是它的核心优势领域
- 对于连续优化问题，不建议直接用 ACO，应考虑 PSO 或 DE
- **数学建模应用建议：**
  - TSP/VRP → 首选 ACO（设计自然，效果优异）
  - 一般组合优化 → GA（更通用）
  - 连续优化 → PSO 或 DE
- 实际使用中，**ACS 变体**（Ant Colony System）通常比基础 ACO 性能更好
