## 📖 算法原理

**逻辑回归** 是最常用的**二分类**模型，用 Sigmoid 函数将线性回归的输出映射到 $[0,1]$ 区间作为概率。

### 模型形式

$$
p(y=1|\mathbf{x}) = \frac{1}{1 + e^{-\mathbf{w}^T \mathbf{x}}}
$$

其中 Sigmoid 函数 $\sigma(z) = 1/(1+e^{-z})$ 将任意实数映射到 $(0,1)$。

**决策边界：** $\mathbf{w}^T \mathbf{x} = 0$（线性边界）。

### 损失函数（交叉熵）

$$
L(\mathbf{w}) = -\sum_{i=1}^{n} \left[ y_i \log(p_i) + (1-y_i) \log(1-p_i) \right]
$$

用**梯度下降**或**牛顿法**求解参数。

---

## 🎯 适用场景

| 问题类型 | 具体例子 |
|---------|---------|
| 二分类 | 是否通过、是否违约、是否患病 |
| 概率预测 | 输出分类概率而非硬分类 |
| 多分类（Softmax 回归） | 手写数字识别（0~9 类） |

---

## 💻 使用方法 (Python)

```python
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import make_classification

X, y = make_classification(n_samples=200, n_features=5, random_state=42)

model = LogisticRegression()
model.fit(X, y)

# 预测概率
probs = model.predict_proba(X[:3])
print(f"预测概率:\n{probs.round(4)}")
print(f"模型系数: {model.coef_.round(3)}")
```
